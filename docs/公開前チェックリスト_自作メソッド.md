### B. ファイルで渡す流れ（人に渡す状況の再現）

自作メソッドは**ブラウザごと**に保存されるので、Safari や別のPCには出てきません（これは仕様です）。別のブラウザや人に渡す方法は2つあります。

**方法1：自作メソッド1個だけを渡す（かんたん。1枚モードでもシーケンスでも）**

1. 元のブラウザで、自作メソッドのタイルの **⚙** → 「**ファイルに保存（.unfoldmethod）**」を押す。または、エディタを開いて、下の左側の「**ファイルに保存**」を押す（保存前の内容でもOK）。`メソッド名.unfoldmethod` がダウンロードフォルダに保存される
2. 別のブラウザ（Safari など）で同じページを開き、方法一覧の最後の「**⇩ファイルから読み込み**」タイルを押して、そのファイルを選ぶ（シーケンスの「読み込み」ボタンに選んでもOK）
3. 「未確認で取り込んだよ」と出て、一覧に「未確認」のタイルが入る。⚙ → 「有効にする（確認してから）」か、シーケンスならバナーの「有効にする」で、使えるようになる

- [x] 方法1：保存 → Safariで読み込み まで通った（作者確認済み 2026-10-03）
- [ ] 方法1：読み込んだあとの「有効にする」まで通した

**方法2：プロジェクトごと渡す（画像や曲も一緒に）**。**シーケンスのページだけ**の機能です。◆が使っている自作メソッドも、ファイルの中に一緒に入ります。

**①（元のブラウザで）`.unfold` を作る**
1. シーケンスのページ（`sequence.html`）を開く。画像を2枚以上並べて、◆（変形）に自作メソッドを選んでおく
2. 画面**下のタイムライン**の、左上に並んだボタン `書き出し｜読み込み｜新規｜保存先…` のうち **「書き出し」** を押す

1. 同じ `sequence.html` を開く（Safari なら Safari で）
2. 同じボタン列の **「読み込み」** → ①のファイルを選ぶ

## 5. 知っておいてほしい限界と注意

- **GPUの本物の固まりは、JavaScriptからは止められません**。ブレーキは「危ない書き方を事前に弾く」「重ければ自動で止める」「落ちたら次の起動で止める」の3段です。ループは合計256回までで、無限ループは書けませんが、重い計算の組み合わせで遅いGPUでは重くなることはあり得ます。その場合も、タブを閉じて開き直せば、そのメソッドは止まった状態で始まります。これは本物のGPUを固めて確認はしていません（危ないので）。
- **古い版は、自作メソッド入りの `.unfold`（version 2）を正しく開けません**。確認したところ、古い公開版では例外は出ませんが、絵がほぼ空になります（タイムラインの表示も `undefined`）。公開直後に再読み込みしていない人や、戻したときに起きます。自作メソッドを使っていないファイルは version 1 のままなので、影響はありません。
- 自作メソッドは**ブラウザごと・サイトごと**に保存されます。別のPC・別のブラウザには引き継がれず、サイトデータを消すと消えます（GLB と同じです）。持ち運ぶ方法は `.unfold` への同梱です。
- 「他の人のファイルは未確認で入る」のは仕様です。渡す相手に一言伝えておくと安心です。
- 自作メソッドを書ける人が増えると、はちゃめちゃなものが出てくるのは、むしろ狙いです。そのぶん、ブレーキは今のまま変えずに公開するのが良いと考えています。
