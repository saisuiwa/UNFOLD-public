# 回転方向・カメラ移動 — ローカル検証 2026-10-04

## 追加した操作

1枚モードの「03 立体」、シーケンスで◆を選んだ「03 選択中」に、共通の「回転方向・カメラの移動」を追加。

- 入りと戻りを別々に、右／左／上／下／右上／左上／右下／左下／回転なしから選択。回転量は0〜3回の整数。異なる軸でも最後は原画の向きに戻る。
- 開始点と終了点を画像パッドまたは数値で指定。開始／終了それぞれのズーム、移動開始・終了秒、速さの変化を指定。
- 「左端から右斜め上へ」「狙った位置へ寄る」「中央で寄って戻す」の見本付き。
- 冒頭と最後は既存のカメラへ滑らかに接続。OFFで従来の描画。回転指定とカメラ指定は別々にON/OFF可能。
- 今回の回転・カメラ操作は両モードで同じ。シーケンスは◆ごとに設定し、立体化しない◆でもカメラは使える。
- カメラは手動で指定した軌道。被写体や粒の自動追跡ではない。

## 保存と実装

`shot-motion.js` が共通の計算、`shot-motion-controls.js` と `shot-motion.css` が共通パネル。`app.js` と `sequence.js` の既存描画に接続しているのでプレビューと動画に同じ設定が適用される。1枚モードの新設定はlocalStorage、シーケンスは既存の自動保存・プロジェクト保存に含まれる。シーケンスはUndo/Redoに対応。
