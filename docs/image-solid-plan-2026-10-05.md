# 画像JavaScriptメソッドの立体化拡張

ユーザー承認範囲：既存の立体・GLBを集まる先として接続し、画像→コード・物理演出→立体→画像へ戻る。両モード共通。既存GLSLと既存コードを保持する。

設計：既存ジオメトリと共通の形状GLSL関数をWorkerへ渡す。画像片の現在の変換行列をGPUで読み、形状頂点の画像UVから対応する片へ結び付ける。物理は固定刻みのまま、表示だけformで立体へ補間する。逆再生時も再構築して決定性を保つ。立体化はホストが担当し、サンプルや既存のcreateImagePlane/Tilesコードを変更不要にする。独自ジオメトリ変形は自動写像の対象外と明示。

1. RED→GREEN：form契約、形状共有関数、ターゲット伝送・GPU集合。
2. 両モード：立体選択・オンオフ・カメラ・深さ・画像切替。編集画面に立体プレビュー。
3. ブラウザ：球・ハート・自作GLB・逆シーク・両モード・保存復元・出力。Node全テスト。独立レビュー、必要修正、ローカル統合。

公開はこの変更の動作確認後の別操作。画像・GLB・曲は外部に送信しない。

記録：既存テストはアーカイブへの参照が必要だったため、メインのarchiveを読み取り用リンクで利用。既存ビルド依存を再利用してインストールしない。

完了：全3工程を実施。独立レビュー2件をRED→GREENで修正。314件とブラウザ検証成功。詳細はimage-solid-verification-2026-10-05.md。
