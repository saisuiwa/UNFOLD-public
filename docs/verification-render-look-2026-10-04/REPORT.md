# UNFOLD 表示比較 — 2026-10-04 検証記録

承認済みのカメラ・光/陰影・半透明比較を既存Three.js描画器へ追加。依存追加・公開デプロイなし。初期値は比較OFF。変更前のappは `archive/app-before-render-look-20261004-143629/` に保存。

## 起動と操作

- プロジェクト: `/Volumes/ORICO/UNFOLD`
- 起動: このディレクトリで `python3 tools/serve.py`。127.0.0.1:8771で起動中。
- 本体: http://127.0.0.1:8771/ —「＋ 自作メソッド」→プレビュー下の「表示比較：カメラ・光・半透明」。画像→プリセット→amount→GLSL→userMethodコピーの流れは維持。
- 本体右側「04–05 演出」にも同じ比較設定。
- シーケンス: http://127.0.0.1:8771/sequence.html —「04 見た目」→同名の比較設定。
- 「調整した表示を使う」をON→遠近感0〜1、光の左右/上下、陰影の強さを調整。半透明は「元の方式」「網点で重ねる（実験）」を選択。
- OFFで元の描画へ戻る。シーケンスでは元からあるカメラ遠近感へ戻る。ON中の遠近感は比較欄を優先。
- エディターの比較はプレビューのみ。「この表示設定を本体にも適用」で本体と動画にも反映。コードのコピーや .unfoldmethod に表示設定は含まれない。シーケンスの設定は既存プロジェクト保存・復元に含む。

## 確認した効果

- 既存シーケンスと同じ、z=0の画像面の大きさを保つ透視カメラを共有。手前の破片が大きく見え、奥行きが読み取りやすい。
- 光方向と陰影強度が変更できる。面の向きを見せるシェーディングであり、物体が他の面へ落とす影の追加ではない。
- 半透明の赤い前面＋青い後面（各alpha=.5）の重なりを検証。元方式の前面先描画は線形RGB (.502,0,0) で後面が消える。網点方式では (.4994,0,.2506)、理論値(.5,0,.25)に近く、描画順を逆転しても全画素一致。alpha0/1も合格。
- 網点は粒状感があり、なめらかなアルファ合成と同一ではない。スクリーン固定パターンのため動く境界ではちらつく可能性がある。ガンマ、縮小、ボケとの相互作用は素材と出力解像度次第。比較用・任意ONの実験機能として維持。
- amount0は不透明/透過画像とも全調整ONで原画像保持を確認。比較OFFの旧版との比較は3プリセット×0/.4/.8×不透明/透過の18条件で平均画素差0。

## 性能（同一条件）

Apple M4 / Chrome154 / ANGLE Metal、960×540、6400粒=12800三角形、花びら、透過45%のテスト画像、amount=.4、時刻1.5固定、AAあり、後処理なし。
ウォームアップ後、各方式15フレーム×15バッチを順序交互で計測しreadPixelsで同期。CPU+GPU+ドライバを含む壁時計時間で、純GPUタイマーや画面全体のFPSではない。

|方式|中央値 ms/frame|p95 ms/frame|
|---|---:|---:|
|元表示|0.613|0.767|
|遠近感＋光|0.560|0.867|
|遠近感＋光＋網点|0.660|0.827|

差は測定揺らぎを含む。高速化を示す結果ではなく、この端末・条件で追加負荷が小さいことを確認したもの。高密度GLB、4K、低性能GPUの保証ではない。全バッチは gpu-results.json。
