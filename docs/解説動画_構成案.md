## 追記（2026-10-03）実際に作って分かったこと

X版の最初の1本（声なし）を作ってみて、上の案を次のように直します。

1. **画像は「物体の写真」ではなく「画面いっぱいの質感」にする。** 立体になるとき、画像は16×16のタイルに割られて形の表面に貼られる（りんごなどのプリセットは、さらにタイルの順番もかき混ぜる）。背景のある写真だと、背景まで形に貼られてしまう。案Aの表の「写真」は、「その中身の質感が画面いっぱいの画像」と読み替える：
   - 地球 → **世界地図（正距円筒図法）の衛星写真風**（球に貼ると地球になる）
   - ドーナツ → **ピンクのアイシングとスプリンクルのマクロ写真**
   - りんご → **赤いりんごの皮のマクロ写真**
2. **立体の途中で、絵が次の画像に入れ替わる**（◆の46〜54%）。だから、形は「前の画像」ではなく「**次の画像**」に合わせる。例：地球の地図 →［ドーナツ形］→ ドーナツ柄。立体の前半は前の画像の質感、後半は次の画像の質感になる。
3. **BGMは先に作って、テンポを測る。** ElevenLabs Music で120BPMを狙った24秒を作成。キックの位置から測ると**ほぼ120**だった。UNFOLD の自動検出は121.49 と出た（24秒で拍が0.3秒近くずれる値）。このときは120で組んだ。（検出のずれは要確認）
4. **画像は Codex 経由で作れた。** `codex exec` で内蔵の画像生成（`image_gen.imagegen`）が動き、1672×941の画像ができた（ChatGPT のプランの範囲内。ComfyのクレジットもElevenLabsも使わない）。ただし、モデルの版（「2.5」かどうか）は、Codex の返事に出なかったので確認できていない。
5. **組み立て方**：UNFOLD で映像だけ書き出し（1080p・60fps・MP4）→ ffmpeg で、BGM（拍に合わせて0.05秒から）・フェードアウト・字幕（透明PNGを重ねる。この ffmpeg には文字の焼き込み機能が無い）を合わせる。再現用のスクリプトは `video/build_x版.py`。
6. **球が本物の地球になるには、「絵柄を混ぜる」を切る。** 球がタイルのモザイクになるのは、変形の途中で画像のタイルを意図的にシャッフルしているため（元の絵を隠す演出）。シーケンスの◆に「絵柄を混ぜる」のオン／オフを足した（初期値オン＝今まで通り）。**世界地図（正距円筒図法）の画像＋オフ → 本物の地球儀**。丸い地球の透過PNGは、球の裏側が透明部分で真っ黒になるので向かない。案2の動画はこれで作った（`video/出力/X版_案2_声なし.mp4`）。
7. **形は「その画像自身の形」にする（案3）。** 立体の途中で次の画像に入れ替わるため、案2は形を「次の画像」に合わせていた（地球が「ドーナツ形」になって不自然）。◆に「**立体は前の画像のまま**」を足して、入れ替えを立体が崩れてからにした。これと「絵柄を混ぜる」オフを組み合わせて、**地球→球（本物の地球儀）、ドーナツ→ドーナツ形、りんご→りんご形**になる。`video/出力/X版_案3_声なし.mp4`。字幕は「地球になる／ドーナツになる／りんごになる」（`build_x版.py` の第3引数 `jibun`）。
8. **案4：真ん中をアニメ調の画像に（作者の指定）。** 地球とりんごはそのまま、ドーナツをやめて、Codex で作った**アニメ調の夕焼けの空**（天の川・流れ星・桜の花びら、`video/images/anime-sky.png`）に。形は、ハート・星・花・土星を比べて、夕焼けの色が一番きれいに残って一目で分かる**ハート**に。崩れ方は、画像の桜の花びらに合わせて「花びらが舞う」。字幕「ハートになる」を追加し、字幕の箱を少し下へ（下の余白 110→60px）。`video/出力/X版_案4_声なし.mp4`（`build_x版.py` の第3引数 `anime`、既定）。
9. **案5：赤く光るりんご＋低音の強いBGM＋展開を曲に合わせる。**
   - りんごの皮の画像をやめて、Codex で作った**赤が主役の光る画像**（赤い絹のような渦と光の粒、`video/images/red-glow.png`）に。形はりんごのまま。さらに「この画像だけの演出」で**光のにじみ**を足して、少し発光させた。
   - BGM：ElevenLabs Music でバス強めの曲（`video/bgm/X版_BGM案2_バス強め_120bpm.mp3`、120BPM・拍の頭0.02秒）。実測すると、**低音は4.0秒（8拍目）で立ち上がり、11.5秒に1拍抜けて、12.0秒（24拍目）で2回目のドロップ**。ただし曲のままだと、低音と高音の差は案1より小さかった（案1が18.3dB、案2が15.2dB）ので、ffmpeg で**低音を持ち上げ（80Hz以下を+9dB）、ドロップ位置（4.0／12.0／18.0／22.0秒）に重低音のヒット（50Hz前後のサイン波が落ちていく音）を足した**（`X版_BGM案2_低音ブースト.wav`、差は22.2dB）。音量は最後に −14 LUFS にそろえる。
   - 展開を曲に合わせる：形が完成する瞬間（◆の約43%）が、ドロップに来るように、ホールドと◆の長さを決めた（ホールド [3.7, 6, 2, 5.3] 拍、◆は各10拍）。**4.0秒に地球儀、12.0秒にハート、18.0秒に赤く光るりんご**が完成する。書き出した動画の低音の立ち上がりを測ると、4.03秒・12.04秒・22.0秒で、狙いどおりだった。字幕の出る時刻もドロップに合わせた。→ `video/出力/X版_案5_形版_低音.mp4`（`build_x版.py` の第3・第4引数 `bass bass`）。
10. **案6：歌詞版（UNFOLD の歌詞機能）。** 字幕のかわりに、UNFOLD の歌詞機能（`05 歌詞MV` の「MVを組む」）で組んだ。歌詞は字幕の重ねではなく、**1行ごとに、画像のタイルが3Dの文字になって、歌詞カードに落ち着く**自動レイアウト。文字は、ドロップ（4.0／12.0／18.0秒）とタイトル（22.0秒）に合わせた。カードの背景の画像は、言葉に合わせて手で入れ替えた（地球の話は地図、ハートはアニメの空、りんごは赤い光＋光のにじみ）。**ただし、歌詞機能の自動レイアウトでは、地球儀・ハート・りんごの「形」は出ない**（形は歌詞の文字だけになる）。→ `video/出力/X版_案6_歌詞版_低音.mp4`（`DURATION=24.0 python3 build_x版.py … none bass0`）。
11. **案7：字幕を小さく・黒い縁取りだけに（作者の指定）。** 案5の字幕を、**小さめ（88→64px、「UNFOLD」のカードは176→128px）・白い文字に黒い縁取りだけ・箱なし**にした（`video/captions_small/`、`build_x版.py` の既定。以前の大きめ・箱ありは `video/captions/`、環境変数 `CAPTION_DIR=captions` で使える）。箱がなくなった分、下の余白は70px。明るい地図の上でも、縁取りで読める。→ `video/出力/X版_案7_形版_字幕小.mp4`（46.0MB・23.5秒・−14.0 LUFS）。
12. 使い方の手順書：`video/UNFOLDの使い方メモ_歌詞と地球.md`（歌詞機能の使い方と、地球を地球っぽくする方法）。歌詞のタイミングファイル：`video/歌詞タイミング_X版.json`（アプリの「タイミング読込」で読める）。
13. 出来た1本（案1・シャッフルあり）：`video/出力/X版_案1_声なし.mp4`（23.5秒・1920×1080・60fps・音量 −14.1 LUFS）。流れは、地球の地図 →（銀河のうずまきで崩れ）→ ドーナツ形 → ドーナツ柄 →（きらめき）→ りんご形 → りんごの皮 →（泡）→ 球 → 地球の地図、で最初に戻ってループ。最後に「UNFOLD／画像が崩れて、立体になる」のカード。

## 2. 「ぐちゃぐちゃ→立体化」でバズりそうな画像

### 画像選びの考え方（UNFOLDの見え方から）

- 立体になるとき、**画像のピクセルがそのまま表面に貼られる**。だから **色数が多くて、模様がはっきりした画像**がきれい（標準の「UNFOLD」タイル画像が、球になったときいちばん映えていたのと同じ理由）。
- **暗い背景＋明るい被写体**は、ネオン・光のにじみ・粒の崩れ方がよく映える。
- 被写体は**中央**に。16:9で作ると「画面いっぱい」にそのまま合う。
- **画像の中身と、立体の形を合わせる**と、一瞬で意味が分かる（ドーナツの写真がドーナツ形に固まる、など）。「なにこれ面白い」が出る一番簡単な仕掛け。
- 最初の1枚が**止まった状態でも**サムネイルとして強いこと。
- **最後に最初の画像へ戻す**と、ループして何度も見られる。

### 案（おすすめ順）

**A．「写真が、その形に固まる」シリーズ ← X版の本命**
形のプリセットに、実物の写真を合わせる。「写真と同じ形になる」が一目で分かる。

| 写真 | 立体の形 | 崩れ方の例 |
|---|---|---|
| 地球（宇宙から） | 球 | 銀河 |
| ドーナツ（ピンクのアイシング・カラフルなトッピング） | ドーナツ | きらめき |
| 赤いりんご | りんご | 泡 |
| 土星 | 土星 | 塵になる |

X版は3つ選んで（例：地球→ドーナツ→りんご→最初の地球へ戻る）約20秒のループ。

**B．「四季ループ」← note版のデモ向き**
崩れ方の**名前と中身が合っている**のが気持ちいい。春→夏→秋→冬→春。

| 画像 | 次へつなぐ崩れ方 |
|---|---|
| 春：満開の桜 | 花びらが舞う |
| 夏：ターコイズの海 | 波紋 |
| 秋：紅葉の山 | 風で飛ぶ |
| 冬：雪の夜の村 | 雪 |

立体化は挟まず「吹き飛んで次が現れる」や「通り抜ける」でもよい。立体にするなら球（時間が回る＝地球）。

**C．「夜のネオン街 → 銀河 → 土星」← 新機能を見せる**
ネオンが映える画像。**「この画像だけの演出」でネオンを夜景にだけ付ける**ので、新機能のデモにもなる（銀河の画像にはネオンが付かない）。

**D．猫がハートになる**
猫は最強のバズ素材だが、解説性は低い。X版の「おまけ」候補。

**E．最後の1枚：立体文字「UNFOLD」**
「追加した形」の立体文字で、タイトルとURLの締めに。

**（任意）シルエット**：形を「次の画像のシルエット」にもできる。ひとつだけ入れると「おっ」となる。

### おすすめ構成

- **X版**：A（3つ）＋ループ。最初に出す1枚は一番きれいなもの。
- **note版**：フック＝A の素材、デモ＝B（四季）と C（ネオン）、締め＝E。
- 画像は合計 **約10枚**（A 3〜4、B 4、C 3）。

## 3. 音

### ナレーション：ElevenLabs v4（`eleven_v4`）

- 2026-09-28 に出たばかりのモデル。**日本語の品質が上がった**と公式に書かれている。1回 10,000文字まで。`[やさしく]`のような**タグで感情や話し方を指示**できる。
- v4 には **Speed／Style のスライダーが無い**（SSMLも使えない）。話す速さは**台本の書き方**（短い文、句読点、間）で調整する。
- 手元のツール（`generate_tts`）は `model_id` に `eleven_v4` を指定できる。
- **声は試聴で決める**：日本語に合う声を3〜4個、同じ短い一文で聞き比べる（これも少しクレジットを使う）。

### BGM：ElevenLabs Music か Suno

| | ElevenLabs Music | Suno |
|---|---|---|
| 私が直接作れるか | **作れる**（`generate_music`。長さも指定、歌なしを指定可） | **作れない**（作者がSunoのサイトで作って、ファイルを渡す） |
| 商用・収益化 | 学習データはライセンス済み。**有料プラン（Starter以上）で商用OK**、YouTubeの収益化もOK。ただし自分で契約するプランでは、映画・テレビ・配信などの一部は対象外 | **無料プランは非商用のみ（収益化できない）**。**Pro以上の有料プランでダウンロードした曲**が商用OK。無料のときに作った曲は、あとから契約しても商用にならない |
| 向いている | 動画の長さ・拍に合わせた**歌なしのBGM**を、すぐ作り直したいとき | メロディや展開が欲しいとき、曲っぽさ重視のとき |

**おすすめ：ElevenLabs Music**（ナレと同じ契約で権利の話がそろう／私が長さと拍に合わせて作り直せる）。Suno は「もっと曲らしいのが欲しい」ときの第二候補。**どちらも、今のプランで商用が使えるかの確認が必要**です。

### 音を先に決めると作りやすい

UNFOLDのシーケンスは **BPMに合わせて拍に吸着**でき、曲入りでMP4に書き出せる。なので：

1. **X版のBGMを先に作る**（歌なし・BPMは固定。例：120。崩れる場所で盛り上がる曲）。
2. その**BPMをシーケンスに入れて**、崩れ・立体化が拍に乗るよう組む。
3. 曲入りでMP4に書き出す。
4. 字幕（テロップ）は、書き出したあとに重ねる。

note版は、UNFOLDの画面を**音なし**で収録して、ナレ・BGM・字幕を**動画編集側（DaVinci Resolve など）**で組み立てる。

## 4. 進め方（案）

1. 画像：各案で**サンプル1枚ずつ**を生成 → 雰囲気を決める → 本番を生成
2. X版：BGM（ElevenLabs Music）→ BPM決定 → UNFOLDでシーケンスを組む → 曲入りMP4 → 字幕を重ねる
3. note版：台本を書く → 声を試聴して決める → ナレを生成 → 画面収録（エディタで流星群を作る場面を含む）→ 組み立て
4. UNFOLDの公開（動画に映る機能が公開版に入っている必要があるので、動画公開より前）
