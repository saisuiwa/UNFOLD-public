# 歌詞・曲 テキストモーション検証

2026-10-04。Chrome / macOS。外部公開なし。テスト音源は人工の660Hzクリック音、歌詞・画像は検証用に作成。

## 検証済み

- Nodeテスト269件（既存242件を含む）、失敗0。
- ブラウザ統合：文字合成、文字OFFで背景pixel一致、シーク再現性、背景0/1枚、見出し/サビ、固定、Undo/Redo、独立した歌詞ドラッグ、歌詞抽出、候補適用/Undo、曲A→B競合、読み込み中の手入力、文字列HTMLの安全な表示、タップ途中停止/再開、保存・再読込。
- 720p/1080p/縦長720×1280で長文・結合文字・絵文字が安全域内。IndexedDBに歌詞と音楽を保存。旧3D歌詞の変換/Undo/Redo。プロジェクト復元が古い音楽読込結果を無効化。
- `lyric-720--2.mp4`：1280×720、24fps、H.264 + AAC、映像10.000秒／音声10.005秒。8秒の曲を2秒遅らせ、冒頭の無音を保持。
- `lyric-1080-2.mp4`：1920×1080、24fps、H.264 + AAC、映像6.000秒／音声6.016秒。曲の2秒地点から開始。
- 実MP4から日本語・強調色・改行を抽出確認。AACの末尾はエンコードフレーム単位で数msの端数あり。

## 独立レビューと修正

新しいレビュアー（gpt-6-astra）がコードと既存テストを確認。Important 4件を一回の修正パスで修正し、再現テストの失敗→成功と全269件成功を確認しました。ブラウザの45項目も全成功。

1. v3から自作メソッドが失われる：対応版を3に更新し、実際のopenProjectFile経路でコード・参照・隔離状態を保持。
2. タップ同期再開が古い歌詞を上書き：歌詞変更で古い同期セッションを無効化し、現在の歌詞から再開。
3. 同文への修正で別行の時刻・固定を流用：前後・位置の一致を優先し、曖昧な重複には他行の状態を流用しない。
4. タイミングJSONで間奏が本文になる：表示用の文章だけでなくイベント種別・原文・強調・時刻出所を保存して往復。

詳細設定（区分、文字BPM、最大表示秒、全行移動、強調/改行補助）と旧連動チェックの非表示も実画面で検証しました。

軽微な保留事項：固定など本文以外の行編集でも原文が再構成され、空行やCRLFが正規化されることがあります。歌詞・時刻・見出しは保持します。

## 判断の記録

- Git管理がないため、改修前アーカイブとORICO内の進行記録で復旧可能にしました。コミット単位の履歴はありません。
- Git履歴の代わりに進行記録を作業完了後も保持します。小さな記録ファイルが残ります。
- レビュアーが独立に判定しなかった画面・GPU合成・MP4は実装担当が実ブラウザとffprobe/抽出フレームで確認しました。視覚品質の独立した二重確認ではありません。
- Safari/モバイル、実ファイル書込中の強制終了、物理的な素材欠損からの復旧は未検証として残します。これらの条件で同じ結果を保証しません。改修前アーカイブは保持します。
