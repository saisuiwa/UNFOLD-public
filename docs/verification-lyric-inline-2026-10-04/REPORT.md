# 歌詞のその場編集・PCフォント — 2026-10-04

## 使い方

タイムラインで歌詞を選ぶと、右側の先頭に「この歌詞を編集」が出ます。

- 動き：6種類の見本をタップして、その行から再生。色と書体は維持します。保存した動きも選べます。
- 色：言葉のボタンか文字のドラッグで範囲を選び、配色をタップ。「ブラウザ」だけの色も変えられます。行全体・全歌詞への配色にも対応。
- 書体：「PCのフォント」を押して参照を許可し、名前で絞って選択。TTF/OTF/WOFF/WOFF2ファイルを選ぶ方法もあります。行全体・全歌詞へ適用できます。

動きの詳細調整と名前付き保存は従来のモーション編集画面を使用。時刻・固定・Undo/Redo・プロジェクト保存を保持します。全歌詞の配色変更は、単語に指定した色を維持します。

## 検証

- Nodeテスト292件、失敗0。
- Chrome既存歌詞統合45件、失敗0。
- その場編集・色・プロジェクト・欠損フォント15件、失敗0。
- モーション描画36件、失敗0。6構成すべてで解像度変更後と新規描画のpixelが完全一致。
- 色面と強調文字の色、単語色の伝達2件、失敗0。
- フォントファイルのIndexedDB再読み込み・ラベル保持・日本語の文字順3件、失敗0。
- PCの710書体を列挙し「07あかずきんポップ Heavy」を選択。Arial.ttfをネイティブファイル選択から読み込み、別ページで保存済みバイナリから復元。
- 実際の日本語PCフォントと単語色でMP4を書き出し。H.264、1280×720、30fps、60フレーム、2秒、674761bytes。中間フレームをデコードして目視確認。

レビューで欠損フォントがプロジェクトの読み込みを中断し自作メソッド登録を戻す問題と、強調文字と背景色面が同色になる問題を修正。欠損フォントは編集用に警告を表示し、動画出力は書体解決まで止めます。

動画確認でCanvasTextureの寸法変更後に古いGPU描画が残る問題を再現。解像度変更時にtexture.dispose()で再確保する修正。再構築を除くと6件の解像度比較が失敗し、戻すと36件すべて成功しました。

## 保存と制限

PCフォントはローカル名を参照。ファイル読込はこのブラウザ・同じURLのIndexedDBへ保存します。フォント本体はプロジェクトやモーションファイルへ埋め込みません。別PC・別ブラウザ・別URLでは同じフォントの指定または再読み込みが必要です。

PC一覧はLocal Font Access APIが使えるChrome/EdgeのPC版向け。非対応・拒否時はファイル読込の案内が出ます。Google Fontsの既存書体も継続して使えます。

画像、曲、フォントファイルは外部送信していません。公開サイトとGitHubはこの作業では更新していません。
