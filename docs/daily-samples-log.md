# 毎日のサンプル追加ログ

毎日のルーティン（手順は [daily-samples-routine.md](daily-samples-routine.md)）が、メソッド・グラフィックモーション・テキストモーションを1つずつ足した記録です。
1行が1つのサンプルで、`id` は `app/guide/samples/` のファイル名（`<id>.jpg` / `<id>.mp4`）と同じです。`node tools/verify_daily.mjs` が、2026-10-04より後に追加された全サンプルがここに載っているかを確かめます。
先頭（新しい日）に足してください。2026-10-04までに入っていた11個（崩れ方5・グラフィック1・テキスト5）は初期分で、ここには載せません。

| 日付 | 種類 | id | 名前 | 工夫したところ・気づき |
|---|---|---|---|---|
| 2026-10-07 | text | `text-bounce` | 落ちて弾む | 上から落ちて床で弾む。補助関数 `bounceOut` を表の上に置いた。動きが速い（0.65秒）ので、静止画は落下の途中（`poster: .14`）。次は「揺れる」「スプリングで着地」など。 |
| 2026-10-07 | graphic | `graphic-stripe-slide` | ストライプスライド | 帯の判定は `p.y` ではなく `cell.y`（タイル単位）にした。`p.y` だと帯の境目の三角形が引き伸ばされる。次は斜めワイプやアイリス。 |
| 2026-10-07 | method | `method-sand-fall` | 砂になって落ちる | 上の粒から順に落とす（`delay` を高さで決める）。`amount` 0.45 だと上半分が落ちきるので、静止画は 0.28（`poster: .28`）。次はインクのにじみ、砂時計など。 |
