# 毎日のサンプル追加ログ

毎日のルーティン（手順は [daily-samples-routine.md](daily-samples-routine.md)）が、メソッド・グラフィックモーション・テキストモーションを1つずつ足した記録です。
1行が1つのサンプルで、`id` は `app/guide/samples/` のファイル名（`<id>.jpg` / `<id>.mp4`）と同じです。`node tools/verify_daily.mjs` が、2026-10-04より後に追加された全サンプルがここに載っているかを確かめます。
先頭（新しい日）に足してください。2026-10-04までに入っていた11個（崩れ方5・グラフィック1・テキスト5）は初期分で、ここには載せません。
