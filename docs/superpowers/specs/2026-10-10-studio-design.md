# UNFOLD STUDIO 設計書

## はじめに — このSTUDIOでできること

PCで1曲分の歌詞MVを作るため、UNFOLD内に独立した編集画面を設けます。「05 STUDIO」を入口にし、画像、短い動画、文字、p5.js系の演出、UNFOLDの変形・立体化を、同じ曲の時間に沿って組み合わせます。シーンは場面を整理する箱であり、素材の種類を制限しません。

曲と歌詞は最初から位置をロックします。映像の並べ替えや削除をしても、歌い出しの時刻は変わりません。ロック中も歌詞の色・動きや曲の音量を変えられます。効果音は独立した音声トラックへ置き、音量・前後のフェードを調整して、曲と一緒に書き出せます。

**初期実用版から、16:9の1曲MVと、同じ作品の区間を抜き出した9:16の宣伝用ショートを作れます。** 曲・歌詞・素材・編集時間軸を共有し、構図だけ横版と縦版で別々に調整します。縦版の文字位置や切り抜きを直しても横版は変わりません。短く書き出すために曲を動かしたり、位置ロックを解除したりする必要はありません。

挿入動画の元音声も初期範囲です。読み込み時に「使う／ミュート」を選び、映像と連動して切り貼りできます。音量・フェードを調整し、主曲・効果音と一緒に書き出します。「崩れない」は重要な内容を切り落とさない既定配置と確認しやすい操作を目標にし、どんな映像も自動で完璧に縦構図へ変換する保証にはしません。

工房は見た目で選ぶ図鑑として使います。「見本を配置」で名前と設定が入り、必要な素材だけ差し替えます。UNFOLD演出は配置ごとに再編集でき、同じ元作品から作った他の配置には変更が波及しません。

画面は工場の制御盤を思わせる落ち着いた外観にしますが、文字の読みやすさ、明確なボタン名、少ない操作を優先します。旧シーケンスは残し、STUDIOの編集データと保存場所は分離します。

**本書は画面・操作・責務の設計案です。画面図も未実装です。実装計画、製品コード変更、依存追加、公開、pushは今回の範囲外です。** 末尾の重要点を確認するユーザーレビューで止めます。

- 曲全体のシーン列・主曲・歌詞・効果音・動画元音声は常に同じ時間目盛りで表示。シーン内のレイヤーや縦版を開いても、別の編集時計には切り替えません。
- 下部は選択シーンだけを展開。曲全体と同じ横ズーム・スクロール・再生位置を使い、「いま何秒か」を見失わせません。
- プレビューは選択版の完成映像を表示し、横／縦切替と同時刻の比較小窓を持つ。音は共通ミックスを1回だけ再生し、比較で二重再生しない。レイヤー選択枠、安全余白ガイドは編集用で、動画には出しません。
- 右の設定欄は選択対象に応じて切り替え、通常操作でコード入力を要求しません。高度なコード編集は工房側に残します。
- 右欄を「共通の内容」と「この版の配置」に分け、対象を文字で明示。「この版の配置」は構図・文字幅等を扱い、「共通の内容」は時間・素材・演出内容を扱う。共通編集は両版へ反映と表示し、縦編集という理由だけで時間軸を複製しません。
- 書き出し欄では版（横／縦）、範囲（全曲／選択区間）、解像度、音声を明示。ショート範囲には作品内の開始・終了と完成尺を併記し、範囲再生にも書き出しと同じ境界音量を反映します。
- 動画元音声は映像の下に関連行として表示し、「使用中／ミュート／音声なし／読込不可」と「リンクON／独立」を区別。音量・フェードはこの行から調整します。
- 主曲と歌詞の「位置固定ON」は文字と鍵で表示。解除後も色だけに頼らず「時間を編集できます」と表示します。
- 工房カードは見本画像・短い用途名・配置ボタンを持つ図鑑。選択時に名前・強さ・形・モーション等の対応設定を自動入力します。外部コードは既存の確認手順を通し、一覧を開くだけで一斉実行しません。
- 制御盤らしさはパネル境界、控えめな状態灯、時間の数字で表現。細すぎる文字、装飾用の大量のつまみ、常時点滅は使いません。小さいPC画面では左棚を折りたたみます。

## 3. シーン・レイヤー・時間の意味

**全曲の時間が基準です。** 0秒は作品の先頭。主曲を最初に入れた時は曲の先頭を0秒へ置き、その長さを作品の長さにします。映像編集では作品の長さを自動変更しません。曲を置き換える場合も勝手に全体を伸縮せず、長さと位置の差を確認できる専用操作にします。

シーンは開始・終了を持つ映像の箱です。初期版はシーン同士を重ねず、シーン境界はカット切替にします。空き時間は作品の背景色を表示。シーン内には画像・動画・自由文字・エフェクト・UNFOLD配置を混在でき、どれも必須ではありません。「動画シーンには文字を置けない」といった制限は設けません。

主曲、歌詞、効果音はシーンの外にある全曲トラックです。歌詞の表示区間や効果音の余韻はシーン境界をまたげます。全曲歌詞はシーン映像より前面に合成。シーン内の自由文字はそのシーンの重ね順に従います。初期版で歌詞を背景の裏に隠す機能は扱いません。

初期の歌詞トラックは現行の1イベントずつ表示を継承します。1つの歌詞イベントを画面内で複数行に改行することは可能です。複数イベントを同時に重ねる歌唱表示は将来拡張です。自由文字レイヤーは複数重ねられます。

動画の元音声は映像にリンクした関連音声として扱い、主曲・歌詞・独立効果音とは区別します。以下の「全て不変」は全曲の独立トラックへの影響です。リンク中の元音声は映像操作と同じ差分・使用区間で変化します（第5節）。横版・縦版はこの共通時間軸を使うため、表の時間編集は両版に反映します。

| 操作 | 映像側の規則 | 主曲・歌詞・効果音への影響 |
| --- | --- | --- |
| シーン移動 | 内容を保ったまま空き区間へ移動。衝突時は拒否し、既存シーンを自動で押さない | 全て不変 |
| シーン挿入 | 空き区間へ配置。途中に入れたい時は既存シーンを分割・トリムして場所を作る | 全て不変 |
| シーン削除 | その区間を空ける。後続を前へ詰めない | 全て不変 |
| 並べ替え | 「この位置へ並べ替え」で選択シーンから移動先までの連続したシーン群だけを並び替える。各長さ・内部内容を保ち、対象群の開始・終了は維持 | 全て不変 |
| 並べ替え対象に空き時間がある | 初期版は上記の並べ替えを無効化。空き区間への移動を使う | 全て不変 |
| シーン端のトリム | 表示範囲だけ変更。残る内容の絶対時刻と素材の再生位置は変えない。後から伸ばすと隠れた範囲を復元 | 全て不変 |
| シーン分割 | 境界で2つの箱に分け、映像が連続するよう内容・素材位置を複製。分割後は独立編集 | 全て不変 |
| シーン内クリップ編集 | そのクリップのみ移動・分割・トリム。シーン外は表示しない。表示範囲外の存在は印で知らせる | 全て不変 |

並べ替えは対象区間内の映像の絶対時刻を変える操作です。実行前のドラッグ表示で影響するシーン群を示します。曲に合わせた映像が動くことは許容しますが、曲や歌詞の時刻を映像に追従させません。移動・並べ替えでは画面に結果を先に示し、確定を1回のUndo単位にします。

### 横16:9と縦9:16 — 共通内容と独立レイアウト

1つの作品に横版・縦版のレイアウト設定を持たせます。素材・時間軸の複製作品を作る方式ではありません。両版は共通の配置ID・歌詞イベントIDを参照します。

| 編集対象 | 反映範囲 |
| --- | --- |
| 素材差し替え、シーン／クリップの移動・長さ・分割・削除・重ね順 | 共通。横縦の両版に反映し、操作欄にその旨を表示 |
| 歌詞本文・開始終了、演出の種類・動き・固定乱数、UNFOLDの形・画像・主要設定 | 共通。位置ロックや配置ごとの独立編集規則は引き続き適用 |
| 音声の使用／ミュート・リンク・音量・クリップフェード | 共通。版切替で別のミックスにしない |
| レイヤーの位置・大きさ・回転、収め方・切り抜き・焦点、余白背景 | 選択版だけ。別版の配置を継続参照せず、それぞれの値を保持 |
| 歌詞・自由文字の表示位置、最大幅、文字サイズ、表示上の改行、安全余白 | 選択版だけ。本文・強調範囲・タイミング・モーションの進行は共通 |
| フォントの種類、文字色、透明度、モーションの種類・強さ | 共通。縦の見やすさを直す操作ではまずサイズ・幅・位置を調整 |
| ショート書き出しの区間と境界フェード | 出力設定だけ。元作品や全曲出力の設定・配置は変更しない |

新規配置時に両版の既定レイアウトを生成し、それ以後の横レイアウト変更が縦へ流れ込む継承はしません。「横の配置から縦を作り直す」は対象と上書き内容を示す明示操作とし、Undo可能にします。複製・分割は両版のレイアウトを新IDへコピーして独立させ、削除は対象IDの両版設定も一緒に履歴へ保存します。素材差し替え後は両版の切り抜き・文字はみ出しを再検査します。

### 縦で崩れにくい配置の規則

縦の収め方は少数の選択肢にします。

1. **全体を収める（既定）**：縦横比を変形させず全体が入る大きさへ縮め、余白を背景色で埋める。重要部分を勝手に切り落とさない。余白背景は単色を既定とし、同じフレームをぼかして敷く選択肢も用意する。背景の複製から音は出さない。
2. **画面いっぱい**：比率を保って拡大し、外側を切り抜く。焦点位置をドラッグして被写体を残す。切れる範囲を横縦比較で確認できるようにする。
3. **手動で配置**：位置・大きさを調整。動く被写体の自動追跡は行わず、焦点を固定したまま外れる場合は警告とプレビューで気付けるようにする。自動検出での警告を保証せず、範囲再生による確認を必須の導線にする。

位置は画面または親レイヤーを基準に0〜1の比率で保持。文字・装飾の大きさは短辺基準で正規化し、縦横で不自然に伸ばさない。装飾のアンカーは画面の中央・端または親レイヤーに結び付け、p5演出の画素座標をそのまま別比率へ流用しません。縦対応していない装飾は横構図を保って全体を収めます。

全曲歌詞・自由文字は縦の最大幅内で再改行します。最大幅の既定案は画面幅の84%、安全余白は左右8%・上下10%を一般ガイドとして調整可能にします。SNS固有の最新UI安全領域を保証する値ではありません。端末での見え方は両版プレビューと実際の出力で確認します。

文字の最小可読サイズの初期案は短辺の3%（1080pxなら約32px）。これは可読性の保証ではなく縮小の下限です。最初に改行し、下限より小さくしないと収まらない場合や安全余白を越える場合は「文字が収まりません」と表示し、表示上の改行・最大幅・位置の調整を促します。警告は書き出し前にも一覧表示し、黙って縮小・欠落させません。本文を短くする操作は共通編集と明示します。表示上の改行は本文や文字IDを変えず、単語強調・文字ごとの動き・歌詞時刻を保ちます。

既存UNFOLD／コード文字モーション等は、自由な縦再配置に対応するものと横構図固定のものを区別します。横構図固定は元の構図全体を収め、既定で切り抜きません。文字込みの固定映像が小さく読みにくい場合は注意を示し、手動配置や別の演出を選べるようにします。「縦用に描画できる」対応済み演出のみ縦サイズと版別カメラ・アンカーで再描画します。対応していない演出を自動で縦対応扱いにしません。

### 区間からショートを書き出す

ショート設定は版ID、開始S、終了E、境界の音声フェードを持ちます。初期は連続する1区間を選び、複数箇所の抜粋を連結する別編集時間軸は作りません。0≦S＜E≦作品長、範囲は出力フレームに合わせて確定値を表示し、書き出し長はE−Sです。

出力0秒を作品S秒に対応させ、以後は「作品時刻=S＋出力時刻」で描画します。曲の配置・歌詞の開始終了は変更せず、位置ロックも解除しません。歌詞、動画、p5、UNFOLDは元の開始からの内部時間で評価し、Sで演出を再スタートしません。Sですでに表示中の歌詞や再生中の音も、その途中の状態から含めます。E以降の映像と音声の余韻は含めません。

音声は同じ[S,E)の主曲・動画元音声・効果音を混ぜ、完成ファイルの時刻だけ0から始めます。境界フェードは既定OFFで、ショート設定にだけ明示追加できます。完成ミックスへ指定した長さの係数を掛け、クリップ本来のフェードや全曲版を変更しません。両端フェードが重なる場合は係数を掛けます。範囲変更で長さを越えたフェードは範囲長に制限し、変更を表示します。

## 4. 位置固定ロックと編集・削除・Undo

位置ロックは「全編集禁止」ではありません。主曲トラックと歌詞トラックに個別の位置ロックを設け、初期値はON。解除はそのトラックの明示操作だけで行い、映像操作や工房配置で解除しません。ロック状態は保存し、再読込後も引き継ぎます。

| 対象・操作 | ロックON | ロック解除後 |
| --- | --- | --- |
| 主曲の開始・使用区間・長さ | 編集不可 | 数値・端の操作で明示編集 |
| 主曲の音量・ミュート | 編集可 | 編集可 |
| 歌詞の開始・終了・一括ずらし・順序 | 編集不可 | 時間操作が可能 |
| 歌詞の色・フォント・位置・文字モーション | 編集可。表示区間は維持 | 編集可 |
| 歌詞の誤字修正 | 同じイベントIDと時刻を保って編集可 | 編集可 |
| 歌詞行の追加・分割・結合・削除・歌詞全体の再取込 | ロック解除を案内して中止。暗黙の時刻再計算をしない | 対象範囲を確認して明示実行 |
| 主曲削除・置き換え | ロック解除を案内して中止 | 専用操作。歌詞を自動で移動しない |

ロック対象を含む複数選択で時間変更・削除した場合は、操作全体を中止します。一部だけ動いて気付かない状態を作りません。ロック解除は確認ダイアログを何度も重ねず、押した対象だけが解除されたことを常時表示します。

Undoは「最後に行った操作の取り消し」であり、新しい時間編集ではありません。ロックを後からONにした場合、最初のUndoはロック操作を戻し、その次は直前の時間編集を戻します。履歴はロック状態を含む同じ作品内の操作順で戻します。復元時にイベントID・時刻・設定・素材参照・版別レイアウト・元音声リンクを一緒に戻し、他の配置や旧シーケンスの履歴に触れません。Redoも同じ単位です。横縦切替は編集履歴を増やさず、Undoボタンには「縦の配置変更」「共通の分割」など戻す対象を表示します。縦配置のUndoは横配置を変更しません。

Deleteはフォーカス中のタイムラインで選択した対象にだけ作用。文字入力中や素材棚のフォーカスではシーンを消しません。シーン削除は内包する映像配置とリンク中の元音声を削除し、曲・歌詞・独立効果音・リンク解除済み音声を削除しません。共通の削除として両版に反映します。リンク中音声だけを選んだDeleteはその音声のミュートとして扱い、映像の削除やリンク解除はしません。元素材のバイト列はその場で消さず、Undoで戻せるよう保持します。保存再読込でUndo履歴はリセットしますが、確定した作品とロック・リンク状態は維持します。

## 5. 主曲・効果音・動画元音声のミックス

効果音は全曲の独立トラックへ、再生位置または指定時刻に置きます。初期版から開始位置、素材の使用区間、長さ、音量、フェードイン・アウトを編集でき、複数音の重なりにも対応する設計です。効果音は主曲・歌詞のロックとは独立して編集できます。映像を動かしても効果音は追従しません。必要な時だけ効果音を選んで移動します。

フェードはクリップの使用区間に対して適用。各フェードの長さはクリップ長以内とし、両方が重なった場合は2つの音量係数を掛けます。トリムで短くなった場合は各フェードを新しい長さ以下に制限し、数値欄にも結果を反映。分割は元のフェード形状が連続するよう区間を分け、切断位置に勝手なフェードを足しません。Undoで元の区間・音量・フェードを復元します。

分割した音声には切断前のフェードの基準点と係数曲線を引き継ぎ、左右の使用区間で切り取って評価します。分割直後に単純な「新しい先頭からのフェード」へ置き換えません。その後ユーザーが片方のフェードを編集した時だけ、選んだ片方の区間へ新しいフェードを適用します。

プレビューと書き出しは同じ配置時刻、素材の使用区間、音量・フェード設定で主曲・効果音・使用中の動画元音声を混ぜます。横縦で同じミックスを使い、ショートの境界フェードだけを出力設定として後段に掛けます。音が重なって上限を超える場合はメーター等で知らせ、ユーザーが音量を調整します。動画内にも同じ曲が入っている場合の二重再生・音割れに注意できるよう、使用中音声を一覧表示します。自動音量調整、ダッキング、ノイズ除去、自動ビート補正は加えません。

**動画の元音声の使用／ミュート、音量・フェード、ミックス・音付き出力を初期版に含めます。** 音声付き動画の読込欄に「元音声を使う／ミュート」を並べ、選んでから配置します。未選択のまま勝手に再生しません。複数読込では選択を全てに適用する操作を用意し、配置後も状態を各クリップへ表示します。音声なし素材は「音声なし」と表示し、音量操作を無効にして映像だけを正常に利用できます。

リンクは初期値ON。映像と元音声は同じ元素材の時刻対応を共有しますが、音声と映像の記録開始時刻に差がある場合はその差も保持し、各トラックの最初のフレームを勝手に同時刻へ揃えません。動画移動・シーン移動・並べ替えは音声も同じ差分で移動。映像トリム・シーン表示範囲で音声の可聴範囲も切り、分割は映像と音声を同時に2組へ分けます。フェードは切断前の形状を保ち、切断位置で追加しません。ミュート中でも対応関係を維持します。これらは主曲・歌詞の位置ロックと独立し、両トラックは動かしません。

リンク中の音声行で時間を操作すると、映像と音声の両方が対象であることを表示して同時編集します。音量・フェード・ミュートの変更は映像に影響しません。独立させたい場合だけ「映像とのリンクを解除」を使い、その時点の絶対開始・使用区間・音量・フェードを独立音声へコピーします。以後は全曲の音声としてシーン外にも置け、映像の移動・削除に追従しません。元の関連音声は置き換わり、同じ音が2本増える処理にはしません。解除はUndoで復元可能。初期版は自動再リンクを行わず、解除のUndo、または独立音声を整理して元動画からリンク音声を作り直す明示操作とします。

解除時の区間はシーンによる切り取りも反映した現在の可聴範囲を使い、解除しただけで隠れていた音が鳴り出さないようにします。後で独立音声の区間を伸ばすことは明示編集として可能です。元音声を作り直す操作では対応する独立音声が残っていないかを表示し、残す／削除を明示選択して重複に気付けるようにします。

音声形式が未対応・破損している場合は「音声読込不可」と理由を表示し、「明示してミュートで使う」か素材差し替えを選べるようにします。「元音声を使う」を選んでいるのにデコードできない状態で、黙って無音出力へ進みません。書き出し時にも不足・エラーを検査します。動画の使用／ミュート切替だけで主曲を止めたり、主曲音量を自動調整したりしません。

## 6. 具体的な操作例

### 例A: 曲に合わせて場面を組む

1. 05からSTUDIOを開き、「新しいMV」を選ぶ。旧シーケンスの作品はそのまま残る。
2. 曲と時刻付き歌詞を入れる。主曲は0秒、歌詞は取り込んだ曲の時刻へ配置し、両トラックを位置固定ONにする。時刻なし歌詞は「仮タイミング」と明示し、ユーザーが歌詞ロックを解除して調整後に再ロックする。仮配置を確定済みと扱わない。
3. 0〜8秒のシーンへ画像を置く。工房で光の見本を選び「見本を配置」。名前と初期設定が入り、画像の上に演出レイヤーができる。
4. 8〜14秒へ短動画と自由文字を置き、元音声を「使う」にして音量とフェードを調整する。動画を分割・トリムすると元音声も同じ位置で切れる。12〜16秒の歌詞は14秒のシーン境界をまたいで表示する。
5. 14〜22秒へサビ用UNFOLD演出、22〜30秒へ別動画を置く。14秒に効果音を置いて音量とフェードを調整。
6. S2を削除しても8〜14秒が空くだけで、14秒のサビ・歌詞・効果音は移動しない。UndoでS2を戻す。
7. 保存後に開き直し、途中へ移動して確認。横版の範囲0〜30秒を曲・動画元音声・効果音付きで書き出す。最終作品では同じ操作を曲の終わりまで行う。

### 例B: 同じUNFOLD演出を2か所で使う

1. 元作品をSTUDIOの素材として読み込み、サビ1へ配置Aを作る。配置時点の設定と必要な依存を作品内へコピーする。
2. Aを複製し、サビ2へ配置Bを作る。画像のバイト列は共有してよいが、設定と編集対象のIDは独立する。
3. Bの「UNFOLD演出を編集」で形・画像・文字・動きを変更する。Aと元作品は変わらない。
4. 編集画面内のプレビューはBの配置内時刻で動く。適用でBだけ更新し、STUDIO本体へ戻る。キャンセルではBも変わらない。適用1回をUndo1回で戻せる。

### 例C: 横MVを保ったまま縦の宣伝ショートを作る

1. 横MVを作った作品で「縦9:16」を選ぶ。横構図固定の素材は全体が収まる状態で表示し、余白は背景色で埋める。
2. 縦版だけ歌詞幅・表示上の改行・位置を調整する。短動画は「画面いっぱい」にし、焦点位置を手動で選ぶ。横との同時刻比較で、横版が変わっていないことを確認する。
3. ショート区間を6〜24秒にする。出力尺は18秒と表示される。主曲・歌詞はロックしたまま、配置を0秒へ動かさない。
4. 範囲再生で、6秒ですでに動いているp5、12〜16秒の歌詞、8〜14秒の動画と元音声、14秒の効果音、14〜22秒のUNFOLDが、元作品と同じ途中状態でつながることを確認する。
5. 終わりが急なら、このショートの終端だけ0.3秒の音声フェードを明示設定する。元の音声クリップや全曲版は変わらない。
6. 縦1080×1920の音付きショートを書き出す。比較として横版の全曲を再表示して、構図・タイミング・音声設定が元のままか確認する。

## 7. データ・時計・描画の境界

これは責務の設計であり、ファイル作成順や実装手順を指定する計画ではありません。

| 境界 | 所有するもの | 外から受ける／返すもの |
| --- | --- | --- |
| 作品データ | 作品ID、長さ、フレーム率、共通シーン・歌詞・音声、ロックと元音声リンク、素材・演出の参照 | 検証済み編集命令を受け、保存可能なデータを返す。DOM・再生機器は持たない |
| 版別レイアウト | 横／縦の版ID、比率・サイズ、配置ID／歌詞IDごとの構図・文字幅・アンカー・カメラ上書き | 共通内容と選択版の値を合わせ、描画設定を返す。別版の値を更新しない |
| 区間出力設定 | 版ID、開始S・終了E、境界フェード | 出力時刻から作品時刻へ対応付ける。共通の配置やロックは変更しない |
| 編集操作 | 選択、ドラッグ、分割、トリム、削除、Undo/Redo | 命令を検証し、変更前後を1操作として確定。描画側から時刻を変更させない |
| 再生時計 | 作品全体の現在時刻・再生／停止・シーク | 全レイヤーへ同じ時刻を渡す。BPMは吸着の目安で、曲や映像を勝手に伸縮しない |
| 素材管理 | 画像、動画、音声、フォント、GLB等のバイト列と必要範囲のキャッシュ | 素材IDと元時間から描画・音声用データを供給。読み取り後は明示解放 |
| レイヤー描画 | 画像／動画／文字／p5系／UNFOLDそれぞれの時刻指定描画 | 版別サイズ・構図、作品から求めた内部時刻、設定、固定乱数を受け、画素と透明度を返す |
| 合成 | シーン背景→下から上のレイヤー→全曲歌詞 | 同一時刻の描画結果を1枚にする。非表示シーンのランタイムは停止・解放 |
| 音声合成 | 主曲・効果音・動画元音声の使用区間、音量、フェード | 共通ミックスを生成。範囲出力時だけ同一区間の抽出と出力境界フェードを適用 |
| 保存・出力 | 作品の検証済みスナップショット | 保存は素材を含む作品。動画出力は時刻指定合成結果と音声を受ける |

映像レイヤーの共通部分は配置ID、種類、開始・長さ、元素材の使用開始、透明度、重ね順、演出設定、関連音声IDを持ちます。変形・収め方・文字サイズ等は版IDごとのレイアウトへ置きます。動画元音声は元素材の音声トラックID、映像とのリンクID、使用状態、音量・フェードを持ち、時間対応を共有します。独立音声化した時だけ絶対時刻の別配置として所有します。速度変更は初期範囲に含めず、動画と音声の速度は1倍です。

時間は保存上の整数マイクロ秒を基準にし、フレーム率を別に保持します。音声はサンプル番号へ、映像は出力フレーム時刻へ変換し、誤差を前フレームから累積させません。UIは秒を表示し、映像の端はフレーム単位、歌詞・音声は必要な細かさで指定します。

シーンは表示区間と内部時間の基準点を別に持ちます。左端トリムは表示区間だけ変更し、内部基準点は動かしません。移動は表示区間と基準点を同じ差分だけ動かします。クリップも表示区間と元時間への対応を分け、左端トリム・分割で再生が0秒へ戻らないようにします。隠れた時間を保持するため、素材の使用開始が負になったり末尾を越えたりする編集は境界で制限します。

主曲と歌詞は作品の絶対時刻を直接持ち、シーンIDを時間の基準にしません。歌詞の内部モーションは「現在の作品時刻−歌詞開始」で計算します。既存歌詞を取り込む時は、現行の曲開始オフセットを一度だけ換算し、背景BPMやシーン長の変更で再換算しません。

プレビューはAudioContextの再生時計を基準に全曲の時刻を求めます。シーク時は古い音声予約と動画フレーム要求を無効化し、新しい時刻から予約し直します。準備が間に合わないときは「準備中」として再生を止め、時計だけ先へ進んだまま古い映像を見せません。読み取り完了の古い結果が新しいシーク位置へ混ざらない識別を持ちます。

書き出しは実時間の再生時計を使わず、フレーム番号から対象時刻を計算します。各素材の準備完了を待ってから合成・圧縮し、同じ区間の音声を別途合成します。描画が遅くても完成動画の時間を伸ばしません。プレビューは低解像度にできても、素材の選択、時刻、設定、重ね順は出力と共有します。

ショートではフレームkの作品時刻をS+k/fps、音声サンプルnの作品時刻をS+n/sampleRateとして、同じSから評価します。合成・エンコード時刻は別に0から付けます。必要な動画キーフレームや状態を持つ演出の前計算はSより前から準備してよいですが、準備区間の画と音は出力しません。Eは含めず、余分な末尾フレーム・音声を足しません。初期30fpsではフレーム整列した区間を使い、将来端数が出る形式を追加する際も音声サンプル丸め誤差を累積させない規則を持ちます。

## 8. UNFOLDとp5系演出の接続

### UNFOLD配置

旧シーケンスの画面・自動保存・再生ループをSTUDIOへそのまま埋め込みません。旧シーケンスを残し、描画に必要な状態を受け取って指定時刻の絵を返す接続部分を分けます。旧画面は従来のデータをその接続部分へ渡す側、STUDIOは配置ごとのコピーを渡す側にします。共通化した描画について、旧作品の表示が変わらないことを受入条件にします。

再編集画面は選択配置の作業コピーだけを扱います。ライブのグローバル`seq`や旧`current`を編集しません。元作品・他配置・工房ライブラリへの逆書き込みはありません。読み込んだメソッド、GLB、設定、演出の版を参照できる形で固定し、工房の更新で既存作品の見た目が自動変更されないようにします。

この「配置ごとの独立」と「横縦のレイアウト独立」は別の境界です。配置Bの形・画像・動きを編集すればBの横縦両版へ反映しますが、配置Aは変わりません。Bの縦構図だけを直す操作ではBの横構図もAも変わりません。対応済みUNFOLDの縦用カメラ上書きは版別レイアウトで持ち、動きの進行・変形の時刻を変えません。

内部の演出長を変えても、STUDIO上の配置枠は自動で伸縮しません。長すぎる部分は枠外として隠し、短くなった場合は末尾フレームを保持して知らせます。枠を伸ばす場合はSTUDIOへ戻り、空き区間の範囲内で明示編集します。元作品の音声・歌詞はUNFOLD映像配置には二重に持ち込まず、初期取込の確認画面で全曲トラックへ一度だけコピーするか選びます。既に主曲・歌詞がある作品には自動追加・上書きしません。置き換えたい時は対象の位置ロックを明示解除し、専用の取込操作を使います。再配置では映像部分だけを配置します。

UNFOLD配置は旧作品の背景を含む矩形映像としても利用でき、その上へ文字・p5系演出を置けます。縦では「横構図を保つ」を既定にして全体を収めます。「縦用に描画」は対応済みと検証できた演出だけで選べるものとし、未対応でも横構図保持によって縦ショートへ配置可能にします。既存の画像メソッドが常に透明背景を返すとは見なさず、UNFOLD内部の背景透過は初期必須範囲に含めません。配置全体の透明度、版別の位置・大きさ・収め方はSTUDIO側が担います。

初期検証でも少なくとも形・画像・主要演出設定を配置ごとに再編集できることを確認します。単なる動画化だけで「再編集対応」としません。一方、既存の全特殊メソッド・GLBまで一度に保証せず、対応集合を画面に示し、非対応作品を黙って別の演出へ置換しません。

### p5系演出

p5.jsコードを現行メソッド欄へ貼る互換性はありません。初期版は横縦両サイズで確認した1種類の承認済み演出から始め、指定内部時刻・版別サイズ・アンカー・固定乱数・設定を受けて透明な画像を返す専用の接続を設けます。自動再生ループや壁時計を演出の時間源にせず、STUDIOから渡す時刻を使います。区間抜出しや比率切替で乱数と演出の進行をリセットしません。再現性は同じ版・同じ時刻・同じ設定で検証し、横と縦の画素が一致することを要求しません。

初期の演出は時刻から絵を直接求められるものに限定します。前フレーム依存の残像、積み上がる粒子、物理演算は、初期化からの固定刻み再計算や途中状態の保存、事前レンダーを必要とする別段階です。乱数を固定するだけでは巻き戻しの一致は保証できません。

実行環境は停止・強制終了・資源解放を持ち、コード確認の手順を既存工房から引き継ぎます。分離実行でGPUクラッシュまで防げるとは約束しません。異常時は原因の配置を示して再生・出力を止め、欠落したまま成功扱いにしません。

## 9. 保存と旧作品の保護

STUDIOは専用DB（名称案 `unfold-studio-projects`）と、作品IDごとの保存を使います。旧`unfold-projects/current`、旧ファイルへの自動保存ハンドル、旧`clearAutosave`、旧未使用素材削除を一切呼びません。別URLにするだけでは保存は分離されないため、保存API自体の分離が必要です。

初期版ではSTUDIO内の素材も作品単位で所有し、同じ作品内だけで重複バイトを共有します。旧作品・工房から入れた素材は原本を残し、STUDIOが所有するコピーを作ります。共有ライブラリは検索・選択の入口として使い、作品からライブラリを削除・上書きしません。旧シーケンスで新規作成や自動保存をしても、STUDIOの素材が削除対象に入らない構成です。

素材を保存してから作品スナップショットを確定します。失敗時は直前の保存済み状態を残し、「未保存」を表示。素材の回収は自動保存のたびに実行せず、作品の確定データ、再編集用コピー、Undo/Redoで参照される素材を保護します。途中終了で残った素材は、保存済み作品が参照していないことを確認して後で回収します。

同じ作品を複数タブで開いた場合は、初期版は1つだけを編集可能にし、他方は閲覧扱いにします。保存時にも版番号を照合し、競合で黙って後勝ちにしません。閲覧側から編集権を明示取得すると、元の編集側は書き込みを停止します。

持ち運び形式はSTUDIO専用（拡張子案 `.unfoldstudio`、形式名とversionを持つ）とし、素材・設定・依存を含めます。キャッシュは含めず、旧`.unfold`への逆変換は初期版に入れません。旧version 1〜4はコピーとして取り込み、原本は残します。既存ファイルがGLB等を完全に内包していない場合はブラウザ内ライブラリから解決し、不足があれば一覧と再指定を要求します。欠落を別形状で代用しません。

共通データ、横縦両レイアウト、ショート範囲と境界フェード、動画元音声の使用状態・トラック選択・リンク・音量設定を同じ作品スナップショットへ保存します。素材参照の保護は両版・独立音声・Undoを含め、縦で見えていないだけの素材を削除しません。読込時は孤立したレイアウトID・リンクIDや区間の範囲外も検査します。共有時間編集で保存済みショート区間に空きが生じても範囲を勝手に動かさず、映像なし区間を知らせます。作品長が短縮され範囲外になった出力設定は、ユーザーが直すまで書き出しを止めます。

新形式の読込は、素材・参照・時刻・版を検証してから現在作品と切り替えます。不正・非対応・素材不足なら現在作品を保持。ファイル保存はSTUDIO用に明示選択した保存先だけへ書き、旧作品のリンク先を引き継ぎません。動画素材が大きくなった時の分割読込・段階的書き込みは検証対象で、現行の全体arrayBuffer読込を無条件に流用しません。

## 10. 初期範囲、性能リスク、エラー表示

初期実用範囲はPCの1曲MVと宣伝用ショート、画像・短動画・自由文字・歌詞・限定したp5系演出・再編集可能なUNFOLD配置・主曲・効果音・動画元音声、横縦独立レイアウト、区間抽出、保存再読込、音付き出力です。**横16:9と縦9:16、動画の元音声は初期必須で、後回しにしません。** 最初の検証条件案は横1920×1080／縦1080×1920・30fpsで、低解像度プレビューを用意します。ブラウザは現行の出力経路に合わせてMacのChromeを最初の検証対象案とします。快適さや全素材への対応を保証する記述ではありません。

動画入力は「拡張子だけで対応判定」せず、実際の映像・音声形式を調べます。初期検証はH.264映像＋AAC音声の短いMP4、音声なし動画、音声だけ未対応のケースを含めます。未対応ファイルは読み込み時に理由を表示します。縦撮影動画の回転情報、可変フレーム率、異なるフレーム率、元音声と映像の記録開始差も時刻対応の検証項目です。入力形式の追加は実測で判断します。

初期範囲外は自動被写体追跡、任意映像の完全自動再構図、SNS別の最新安全領域保証、縦版だけ別のカット順にする独立編集時間軸、複数抜粋の自動連結、自動音量調整、速度変更、シーン間の重なり・高度な遷移、任意p5.jsの無変更実行、高度な音声編集、共同編集、モバイル最適化、4Kや無制限レイヤーの保証です。元音声のリンク解除による独立編集、3種類の音声ミックス、フェード、音付きショートは初期範囲です。

| 主なリスク | 設計上の対処・測るもの |
| --- | --- |
| 動画シークと音声同期 | 指定フレームの読取完了を待つ。連続再生・逆方向シーク・書き出しで同じ素材時刻か確認 |
| 横から縦への再配置 | 全体を収める既定、版別の切り抜きと文字幅。動く被写体や長文は範囲再生で確認し、全自動の成功を約束しない |
| 区間頭での演出・音の再スタート | 内部時刻をSから評価し、必要な前計算を行う。完成ファイルの時刻だけ0に付け直す |
| 動画元音声の二重再生・音割れ | リンク解除で音声を複製再生しない。使用中一覧とメーターで手動調整。元音声が曲を含む場合はミュートを選べる |
| 1曲分のメモリ | 動画を全フレーム展開せず必要区間を保持。キャッシュ上限と解放を測定。出力データ全保持の現行方式も再評価 |
| 多重WebGL・コード演出 | 必要な配置だけ稼働。横縦比較小窓は低解像度・更新頻度を落とせるようにし、主プレビューと音の時計を遅らせない。プレビュー解像度と同時演出数を測定 |
| 状態を持つ演出の巻き戻し | 時刻から直接描く演出を先行。固定刻み再計算の待ち時間・一致は別途評価 |
| 旧シーケンスの描画共通化 | 既存作品の代表例で以前の表示と比較。保存・UIの共有は避ける |
| 音声出力や保存の失敗 | 無音出力・未保存を成功表示しない。原因と選べる形式／保存先を示し、作業状態を保持 |

長尺・多レイヤーの性能は、実際のMac・ブラウザ・素材で測定します。実装速度、納期、処理が実時間より速いことは約束しません。

## 11. 段階と受入条件

以下は設計の検証段階です。詳細な実装計画や作業開始の承認ではありません。

### 段階1: 約30秒の混合シーンで編集から横縦出力まで確認

小さな機能セットで、画像＋1種類のp5系演出、音声付き短動画＋文字、再編集可能なUNFOLD、別動画を同じ時間軸へ置きます。主曲・歌詞・効果音・動画元音声、ロックとリンク、横縦独立レイアウト、保存再読込、シーク、全範囲と選択区間の音付き書き出しまで含めます。装飾UIだけのデモ、横だけの出力、無音動画で完了としません。

最低限の検証作品は0〜8秒、8〜14秒、14〜22秒、22〜30秒の4シーン。12〜16秒の歌詞でシーン越境、14秒の効果音で開始同期、音声付き短動画の途中トリムで映像と音の元時間保持を確かめます。同じUNFOLD設定の2配置を一時的に作り、片方だけ再編集できることも確認します。

横縦それぞれの0〜30秒と、縦の6〜24秒（18秒ショート）を出力します。さらに開始を9秒・13秒・18秒へ変えた短い区間で、動画元音声・歌詞・UNFOLDの途中から正しく始まることを確認。縦構図と改行を変更し、ショート終端にフェードを加えても、横版レイアウトと共通音声・時刻データは不変であることを確認します。音声の使用／ミュート、リンク解除、長文警告、音声なし／音声未対応の挙動も含めます。

### 段階2: 1曲を仕上げられる実用版

段階1の仕組みに、使いやすいシーン／レイヤー編集、工房の見本配置、横縦比較、文字・構図の警告、取り消し、明確なエラーと保存復旧を揃えます。代表的な1曲を最初から最後まで編集・保存・再読込・横MV出力し、そのサビを縦ショートとして音付きで抜き出します。資源の使用量と待ち時間を記録し、扱える入力形式・同時演出・出力条件を実測に基づき示します。

### 段階3: 実測後の拡張

p5系演出の追加、前フレーム依存演出、縦用に直接描画できるUNFOLDメソッドの拡大、16:9／9:16以外の比率や入力形式の追加を個別に検討します。自動被写体追跡や別カット順の縦編集など、初期範囲外の機能は新たな設計判断を経ます。

| 受入項目 | 合格条件 |
| --- | --- |
| 位置ロック | ON中の映像移動・挿入・削除・トリム・並べ替え前後で主曲の配置・使用区間、全歌詞IDの開始・終了が完全一致。効果音も変化しない |
| ロックの意味 | 色・文字モーション・主曲音量は変更可能。時間操作と対象削除は拒否。解除したトラックだけ時間編集できる |
| 分割・トリム | 切断の前後で動画・UNFOLD・音の元時間が飛ばない。シーン左トリムで残る内容が動かず、再延長で復元 |
| 並べ替え・削除 | 対象映像だけが規則どおり変化。削除で空き時間を詰めない。衝突移動と空きを含む並べ替えは明示拒否 |
| 歌詞の越境 | 12〜16秒の歌詞が14秒のシーン切替でも途切れず、モーションも再スタートしない |
| 効果音・動画元音声 | 主曲と重なり、使用／ミュート・音量・フェードがプレビューと横縦の出力に反映。比較小窓や余白ぼかしから二重に音が鳴らない |
| 元音声リンク | リンク中の移動・シーン並べ替え・分割・トリム・削除が映像と一致。主曲と歌詞は不変。解除後は独立編集でき、二重再生せず、Undoで元の対応を復元 |
| 音声入力異常 | 音声なしは映像のみ正常利用。未対応音声は理由表示と明示ミュート／差し替え。使用中なのに無音で成功扱いにしない |
| 横縦の非破壊編集 | 縦の位置・文字幅・改行・焦点・カメラ上書き変更前後で横のレイアウトデータが完全一致。共通の素材差し替え・時間編集は両版に反映と明示 |
| 構図と文字 | 横素材は縦で比率を保って全体表示。全面表示では焦点調整可。長文は改行し、最小サイズ以下へ黙って縮小しない。安全余白ガイド調整可。横構図固定UNFOLDは切らずに表示 |
| ショートの時間 | 6〜24秒を18秒で出力。主曲・歌詞ロックを維持し、元データの時刻は完全不変。開始9秒／13秒／18秒でも動画・音声・歌詞・p5・UNFOLDが途中状態から再現 |
| ショートの音 | 合成前音声は同じ作品区間のサンプルと一致。境界フェードON時はその係数だけ変わり、元クリップ・全曲出力は不変。E以降の音を含めない |
| シークと出力 | 同一解像度の合成前フレームについて、順再生・任意シーク・書き出しで素材時刻、重ね順、歌詞、乱数結果が一致。GPU・圧縮差の完全なバイト一致は要求しない |
| 音声同期 | 合成前音声の曲・効果音・動画元音声の開始・終了位置がサンプル単位で一致。圧縮後の横MV・縦ショートでも視覚マーカーと音のズレが30fpsの1フレーム以内。区間頭・末尾・曲終端で累積ずれなし |
| UNFOLD独立性 | Bの編集・適用・UndoでAと元作品とライブラリのデータが変化しない。再読込後も保持 |
| Undo/Redo | 複合操作を1回で復元。ロック・設定・素材参照を含め整合。文字入力中Deleteでシーンが消えない |
| 保存分離 | 旧シーケンスの自動保存・新規作成・素材削除後もSTUDIOが再読込可能。逆方向も旧作品が変化しない |
| ファイル往復 | キャッシュのない状態で専用ファイルを開き、素材・横縦レイアウト・ショート範囲・境界フェード・音声リンク／ミュートが復元。不足・破損・非対応版は現在作品を壊さない |
| 異常系 | 容量不足、出力非対応、コード演出エラー、中止を成功表示しない。最後の保存と編集状態を保護 |
| 1曲検証 | 曲末尾まで出力・再生確認。複数回のシーク・読込・演出切替後に資源が増え続けない。機材・素材・使用量・待ち時間を記録 |

## 12. ユーザーレビューで確認する重要点

横16:9／縦9:16と動画元音声の初期対応は確定要件です。再び採否を質問しません。位置ロック・効果音・独立したUNFOLD再編集も維持します。レビューで確認する残点は次の操作方針だけです。

1. **ショートの構成**：初期は同じカット順の連続した1区間を抜き出し、縦の構図だけ直す案でよいか。複数箇所をつないだ宣伝編集が必須なら、別の時間軸を持つ範囲を追加で設計する必要がある。
2. **映像の組み替え**：挿入・削除では時間を詰めず、並べ替えだけ対象区間内の映像とリンク元音声を動かす案でよいか。主曲・歌詞・独立音声は動かさない。

検証条件案は横1920×1080／縦1080×1920・30fps、MacのChrome。普段使う動画形式や必須ブラウザが異なる場合は検証素材を追加する。縦の余白は単色を既定、元音声は読込時の明示選択とし、追加の好み確認がなくても設計レビューができる具体案とする。
