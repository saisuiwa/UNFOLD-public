# UNFOLD STUDIO 設計書

2026-10-10 / ユーザーレビュー用 / 未実装

## はじめに — このSTUDIOでできること

PCで1曲分の歌詞MVを作るため、UNFOLD内に独立した編集画面を設けます。「05 STUDIO」を入口にし、画像、短い動画、文字、p5.js系の演出、UNFOLDの変形・立体化を、同じ曲の時間に沿って組み合わせます。シーンは場面を整理する箱であり、素材の種類を制限しません。

曲と歌詞は最初から位置をロックします。映像の並べ替えや削除をしても、歌い出しの時刻は変わりません。ロック中も歌詞の色・動きや曲の音量を変えられます。効果音は独立した音声トラックへ置き、音量・前後のフェードを調整して、曲と一緒に書き出せます。

工房は見た目で選ぶ図鑑として使います。「見本を配置」で名前と設定が入り、必要な素材だけ差し替えます。UNFOLD演出は配置ごとに再編集でき、同じ元作品から作った他の配置には変更が波及しません。

画面は工場の制御盤を思わせる落ち着いた外観にしますが、文字の読みやすさ、明確なボタン名、少ない操作を優先します。旧シーケンスは残し、STUDIOの編集データと保存場所は分離します。

**本書は画面・操作・責務の設計案です。画面図も未実装です。実装計画、製品コード変更、依存追加、公開、pushは今回の範囲外です。** 末尾の重要点を確認するユーザーレビューで止めます。

## 3. シーン・レイヤー・時間の意味

**全曲の時間が基準です。** 0秒は作品の先頭。主曲を最初に入れた時は曲の先頭を0秒へ置き、その長さを作品の長さにします。映像編集では作品の長さを自動変更しません。曲を置き換える場合も勝手に全体を伸縮せず、長さと位置の差を確認できる専用操作にします。

シーンは開始・終了を持つ映像の箱です。初期版はシーン同士を重ねず、シーン境界はカット切替にします。空き時間は作品の背景色を表示。シーン内には画像・動画・自由文字・エフェクト・UNFOLD配置を混在でき、どれも必須ではありません。「動画シーンには文字を置けない」といった制限は設けません。

主曲、歌詞、効果音はシーンの外にある全曲トラックです。歌詞の表示区間や効果音の余韻はシーン境界をまたげます。全曲歌詞はシーン映像より前面に合成。シーン内の自由文字はそのシーンの重ね順に従います。初期版で歌詞を背景の裏に隠す機能は扱いません。

初期の歌詞トラックは現行の1行ずつ表示を継承します。複数行の自由な同時歌唱表示は将来拡張です。自由文字レイヤーは複数重ねられます。

| 操作 | 映像側の規則 | 主曲・歌詞・効果音への影響 |
| --- | --- | --- |
| シーン移動 | 内容を保ったまま空き区間へ移動。衝突時は拒否し、既存シーンを自動で押さない | 全て不変 |
| シーン挿入 | 空き区間へ配置。途中に入れたい時は既存シーンを分割・トリムして場所を作る | 全て不変 |
| シーン削除 | その区間を空ける。後続を前へ詰めない | 全て不変 |
| 並べ替え | 「この位置へ並べ替え」で選択シーンから移動先までの連続したシーン群だけを並び替える。各長さ・内部内容を保ち、対象群の開始・終了は維持 | 全て不変 |
| 並べ替え対象に空き時間がある | 初期版は上記の並べ替えを無効化。空き区間への移動を使う | 全て不変 |
| シーン端のトリム | 表示範囲だけ変更。残る内容の絶対時刻と素材の再生位置は変えない。後から伸ばすと隠れた範囲を復元 | 全て不変 |
| シーン分割 | 境界で2つの箱に分け、映像が連続するよう内容・素材位置を複製。分割後は独立編集 | 全て不変 |
| シーン内クリップ編集 | そのクリップのみ移動・分割・トリム。シーン外は表示しない。表示範囲外の存在は印で知らせる | 全て不変 |

並べ替えは対象区間内の映像の絶対時刻を変える操作です。実行前のドラッグ表示で影響するシーン群を示します。曲に合わせた映像が動くことは許容しますが、曲や歌詞の時刻を映像に追従させません。移動・並べ替えでは画面に結果を先に示し、確定を1回のUndo単位にします。

## 4. 位置固定ロックと編集・削除・Undo

位置ロックは「全編集禁止」ではありません。主曲トラックと歌詞トラックに個別の位置ロックを設け、初期値はON。解除はそのトラックの明示操作だけで行い、映像操作や工房配置で解除しません。ロック状態は保存し、再読込後も引き継ぎます。

| 対象・操作 | ロックON | ロック解除後 |
| --- | --- | --- |
| 主曲の開始・使用区間・長さ | 編集不可 | 数値・端の操作で明示編集 |
| 主曲の音量・ミュート | 編集可 | 編集可 |
| 歌詞の開始・終了・一括ずらし・順序 | 編集不可 | 時間操作が可能 |
| 歌詞の色・フォント・位置・文字モーション | 編集可。表示区間は維持 | 編集可 |
| 歌詞の誤字修正 | 同じイベントIDと時刻を保って編集可 | 編集可 |
| 歌詞行の追加・分割・結合・削除・歌詞全体の再取込 | ロック解除を案内して中止。暗黙の時刻再計算をしない | 対象範囲を確認して明示実行 |
| 主曲削除・置き換え | ロック解除を案内して中止 | 専用操作。歌詞を自動で移動しない |

ロック対象を含む複数選択で時間変更・削除した場合は、操作全体を中止します。一部だけ動いて気付かない状態を作りません。ロック解除は確認ダイアログを何度も重ねず、押した対象だけが解除されたことを常時表示します。

Undoは「最後に行った操作の取り消し」であり、新しい時間編集ではありません。ロックを後からONにした場合、最初のUndoはロック操作を戻し、その次は直前の時間編集を戻します。履歴はロック状態を含む同じ作品内の操作順で戻します。復元時にイベントID・時刻・設定・素材参照を一緒に戻し、他の配置や旧シーケンスの履歴に触れません。Redoも同じ単位です。

Deleteはフォーカス中のタイムラインで選択した対象にだけ作用。文字入力中や素材棚のフォーカスではシーンを消しません。シーン削除は内包する映像配置のみ削除し、曲・歌詞・効果音を削除しません。元素材のバイト列はその場で消さず、Undoで戻せるよう保持します。保存再読込でUndo履歴はリセットしますが、確定した作品とロック状態は維持します。

## 5. 効果音と主曲のミックス

効果音は全曲の独立トラックへ、再生位置または指定時刻に置きます。初期版から開始位置、素材の使用区間、長さ、音量、フェードイン・アウトを編集でき、複数音の重なりにも対応する設計です。効果音は主曲・歌詞のロックとは独立して編集できます。映像を動かしても効果音は追従しません。必要な時だけ効果音を選んで移動します。

フェードはクリップの使用区間に対して適用。各フェードの長さはクリップ長以内とし、両方が重なった場合は2つの音量係数を掛けます。トリムで短くなった場合は各フェードを新しい長さ以下に制限し、数値欄にも結果を反映。分割は元のフェード形状が連続するよう区間を分け、切断位置に勝手なフェードを足しません。Undoで元の区間・音量・フェードを復元します。

プレビューと書き出しは同じ配置時刻、素材の使用区間、音量・フェード設定で主曲と効果音を混ぜます。音が重なって上限を超える場合はメーター等で知らせ、ユーザーが音量を調整します。自動音量調整、ダッキング、ノイズ除去、自動ビート補正は加えません。

**挿入動画の元音声は初期版ではミュート固定案です。** 表示は「元音声なし」とし、動画を入れただけで二重に音が鳴ることを避けます。将来、明示した「元音声を別トラックへ取り出す」で独立音声クリップにする境界を残します。動画の配置だけでは主曲を止めません。

## 6. 具体的な操作例

### 例A: 曲に合わせて場面を組む

1. 05からSTUDIOを開き、「新しいMV」を選ぶ。旧シーケンスの作品はそのまま残る。
2. 曲と時刻付き歌詞を入れる。主曲は0秒、歌詞は取り込んだ曲の時刻へ配置し、両トラックを位置固定ONにする。時刻なし歌詞は「仮タイミング」と明示し、ユーザーが歌詞ロックを解除して調整後に再ロックする。仮配置を確定済みと扱わない。
3. 0〜8秒のシーンへ画像を置く。工房で光の見本を選び「見本を配置」。名前と初期設定が入り、画像の上に演出レイヤーができる。
4. 8〜14秒へ短動画と自由文字を置く。動画の元音声は鳴らない。12〜16秒の歌詞は14秒のシーン境界をまたいで表示する。
5. 14〜22秒へサビ用UNFOLD演出、22〜30秒へ別動画を置く。14秒に効果音を置いて音量とフェードを調整。
6. S2を削除しても8〜14秒が空くだけで、14秒のサビ・歌詞・効果音は移動しない。UndoでS2を戻す。
7. 保存後に開き直し、途中へ移動して確認。範囲0〜30秒を音付きで書き出す。最終作品では同じ操作を曲の終わりまで行う。

### 例B: 同じUNFOLD演出を2か所で使う

1. 元作品をSTUDIOの素材として読み込み、サビ1へ配置Aを作る。配置時点の設定と必要な依存を作品内へコピーする。
2. Aを複製し、サビ2へ配置Bを作る。画像のバイト列は共有してよいが、設定と編集対象のIDは独立する。
3. Bの「UNFOLD演出を編集」で形・画像・文字・動きを変更する。Aと元作品は変わらない。
4. 編集画面内のプレビューはBの配置内時刻で動く。適用でBだけ更新し、STUDIO本体へ戻る。キャンセルではBも変わらない。適用1回をUndo1回で戻せる。

## 7. データ・時計・描画の境界

これは責務の設計であり、ファイル作成順や実装手順を指定する計画ではありません。

| 境界 | 所有するもの | 外から受ける／返すもの |
| --- | --- | --- |
| 作品データ | 作品ID、長さ、画面比率、フレーム率、シーン、全曲音声・歌詞、ロック、素材・演出の参照 | 検証済み編集命令を受け、保存可能なデータを返す。DOM・再生機器は持たない |
| 編集操作 | 選択、ドラッグ、分割、トリム、削除、Undo/Redo | 命令を検証し、変更前後を1操作として確定。描画側から時刻を変更させない |
| 再生時計 | 作品全体の現在時刻・再生／停止・シーク | 全レイヤーへ同じ時刻を渡す。BPMは吸着の目安で、曲や映像を勝手に伸縮しない |
| 素材管理 | 画像、動画、音声、フォント、GLB等のバイト列と必要範囲のキャッシュ | 素材IDと元時間から描画・音声用データを供給。読み取り後は明示解放 |
| レイヤー描画 | 画像／動画／文字／p5系／UNFOLDそれぞれの時刻指定描画 | サイズ、対象時刻、設定、固定乱数を受け、画素と透明度を返す |
| 合成 | シーン背景→下から上のレイヤー→全曲歌詞 | 同一時刻の描画結果を1枚にする。非表示シーンのランタイムは停止・解放 |
| 音声合成 | 主曲・効果音の使用区間、音量、フェード | プレビュー音と書き出し用サンプルを同じ規則から生成 |
| 保存・出力 | 作品の検証済みスナップショット | 保存は素材を含む作品。動画出力は時刻指定合成結果と音声を受ける |

映像レイヤーは配置ID、種類、開始・長さ、元素材の使用開始、変形、透明度、重ね順、演出設定を持ちます。速度変更は初期範囲に含めず、動画と音声の速度は1倍です。

時間は保存上の整数マイクロ秒を基準にし、フレーム率を別に保持します。音声はサンプル番号へ、映像は出力フレーム時刻へ変換し、誤差を前フレームから累積させません。UIは秒を表示し、映像の端はフレーム単位、歌詞・音声は必要な細かさで指定します。

シーンは表示区間と内部時間の基準点を別に持ちます。左端トリムは表示区間だけ変更し、内部基準点は動かしません。移動は表示区間と基準点を同じ差分だけ動かします。クリップも表示区間と元時間への対応を分け、左端トリム・分割で再生が0秒へ戻らないようにします。隠れた時間を保持するため、素材の使用開始が負になったり末尾を越えたりする編集は境界で制限します。

主曲と歌詞は作品の絶対時刻を直接持ち、シーンIDを時間の基準にしません。歌詞の内部モーションは「現在の作品時刻−歌詞開始」で計算します。既存歌詞を取り込む時は、現行の曲開始オフセットを一度だけ換算し、背景BPMやシーン長の変更で再換算しません。

プレビューはAudioContextの再生時計を基準に全曲の時刻を求めます。シーク時は古い音声予約と動画フレーム要求を無効化し、新しい時刻から予約し直します。準備が間に合わないときは「準備中」として再生を止め、時計だけ先へ進んだまま古い映像を見せません。読み取り完了の古い結果が新しいシーク位置へ混ざらない識別を持ちます。

書き出しは実時間の再生時計を使わず、フレーム番号から対象時刻を計算します。各素材の準備完了を待ってから合成・圧縮し、同じ区間の音声を別途合成します。描画が遅くても完成動画の時間を伸ばしません。プレビューは低解像度にできても、素材の選択、時刻、設定、重ね順は出力と共有します。

## 8. UNFOLDとp5系演出の接続

### UNFOLD配置

旧シーケンスの画面・自動保存・再生ループをSTUDIOへそのまま埋め込みません。旧シーケンスを残し、描画に必要な状態を受け取って指定時刻の絵を返す接続部分を分けます。旧画面は従来のデータをその接続部分へ渡す側、STUDIOは配置ごとのコピーを渡す側にします。共通化した描画について、旧作品の表示が変わらないことを受入条件にします。

再編集画面は選択配置の作業コピーだけを扱います。ライブのグローバル`seq`や旧`current`を編集しません。元作品・他配置・工房ライブラリへの逆書き込みはありません。読み込んだメソッド、GLB、設定、演出の版を参照できる形で固定し、工房の更新で既存作品の見た目が自動変更されないようにします。

内部の演出長を変えても、STUDIO上の配置枠は自動で伸縮しません。長すぎる部分は枠外として隠し、短くなった場合は末尾フレームを保持して知らせます。枠を伸ばす場合はSTUDIOへ戻り、空き区間の範囲内で明示編集します。元作品の音声・歌詞はUNFOLD映像配置には二重に持ち込まず、初期取込の確認画面で全曲トラックへ一度だけコピーするか選びます。既に主曲・歌詞がある作品には自動追加・上書きしません。置き換えたい時は対象の位置ロックを明示解除し、専用の取込操作を使います。再配置では映像部分だけを配置します。

初期のUNFOLD配置は旧作品の背景を含む矩形映像として合成し、その上へ文字・p5系演出を置けます。既存の画像メソッドが常に透明背景を返すとは見なさず、UNFOLD内部の背景透過は初期必須範囲に含めません。配置全体の透明度・位置・大きさの調整はSTUDIO側が担います。

初期検証でも少なくとも形・画像・主要演出設定を配置ごとに再編集できることを確認します。単なる動画化だけで「再編集対応」としません。一方、既存の全特殊メソッド・GLBまで一度に保証せず、対応集合を画面に示し、非対応作品を黙って別の演出へ置換しません。

### p5系演出

p5.jsコードを現行メソッド欄へ貼る互換性はありません。初期版は1種類の承認済み演出から始め、指定時刻・サイズ・固定乱数・設定を受けて透明な画像を返す専用の接続を設けます。自動再生ループや壁時計を演出の時間源にせず、STUDIOから渡す時刻を使います。

初期の演出は時刻から絵を直接求められるものに限定します。前フレーム依存の残像、積み上がる粒子、物理演算は、初期化からの固定刻み再計算や途中状態の保存、事前レンダーを必要とする別段階です。乱数を固定するだけでは巻き戻しの一致は保証できません。

実行環境は停止・強制終了・資源解放を持ち、コード確認の手順を既存工房から引き継ぎます。分離実行でGPUクラッシュまで防げるとは約束しません。異常時は原因の配置を示して再生・出力を止め、欠落したまま成功扱いにしません。

## 9. 保存と旧作品の保護

STUDIOは専用DB（名称案 `unfold-studio-projects`）と、作品IDごとの保存を使います。旧`unfold-projects/current`、旧ファイルへの自動保存ハンドル、旧`clearAutosave`、旧未使用素材削除を一切呼びません。別URLにするだけでは保存は分離されないため、保存API自体の分離が必要です。

初期版ではSTUDIO内の素材も作品単位で所有し、同じ作品内だけで重複バイトを共有します。旧作品・工房から入れた素材は原本を残し、STUDIOが所有するコピーを作ります。共有ライブラリは検索・選択の入口として使い、作品からライブラリを削除・上書きしません。旧シーケンスで新規作成や自動保存をしても、STUDIOの素材が削除対象に入らない構成です。

素材を保存してから作品スナップショットを確定します。失敗時は直前の保存済み状態を残し、「未保存」を表示。素材の回収は自動保存のたびに実行せず、作品の確定データ、再編集用コピー、Undo/Redoで参照される素材を保護します。途中終了で残った素材は、保存済み作品が参照していないことを確認して後で回収します。

同じ作品を複数タブで開いた場合は、初期版は1つだけを編集可能にし、他方は閲覧扱いにします。保存時にも版番号を照合し、競合で黙って後勝ちにしません。閲覧側から編集権を明示取得すると、元の編集側は書き込みを停止します。

持ち運び形式はSTUDIO専用（拡張子案 `.unfoldstudio`、形式名とversionを持つ）とし、素材・設定・依存を含めます。キャッシュは含めず、旧`.unfold`への逆変換は初期版に入れません。旧version 1〜4はコピーとして取り込み、原本は残します。既存ファイルがGLB等を完全に内包していない場合はブラウザ内ライブラリから解決し、不足があれば一覧と再指定を要求します。欠落を別形状で代用しません。

新形式の読込は、素材・参照・時刻・版を検証してから現在作品と切り替えます。不正・非対応・素材不足なら現在作品を保持。ファイル保存はSTUDIO用に明示選択した保存先だけへ書き、旧作品のリンク先を引き継ぎません。動画素材が大きくなった時の分割読込・段階的書き込みは検証対象で、現行の全体arrayBuffer読込を無条件に流用しません。

## 10. 初期範囲、性能リスク、エラー表示

初期実用範囲はPCの1曲MV、画像・短動画・自由文字・歌詞・限定したp5系演出・再編集可能なUNFOLD配置・主曲・効果音、保存再読込、音付き出力です。横長16:9・1080p・30fpsを最初の検証条件案とし、低解像度プレビューを用意します。ブラウザは現行の出力経路に合わせてMacのChromeを最初の検証対象案とします。快適さや全素材への対応を保証する記述ではありません。

動画入力は「拡張子だけで対応判定」せず、実際の映像・音声形式を調べます。初期検証はH.264の短いMP4から始め、未対応ファイルは読み込み時に理由を表示します。可変フレーム率、回転情報、異なるフレーム率も時刻対応の検証項目です。入力形式の追加は実測で判断します。

初期範囲外は動画元音声の取り出し、自動音量調整、速度変更、シーン間の重なり・高度な遷移、任意p5.jsの無変更実行、高度な音声編集、共同編集、モバイル最適化、4Kや無制限レイヤーの保証です。通常の編集だけで必要な効果音ミックス・フェード・音付き出力は後回しにしません。

| 主なリスク | 設計上の対処・測るもの |
| --- | --- |
| 動画シークと音声同期 | 指定フレームの読取完了を待つ。連続再生・逆方向シーク・書き出しで同じ素材時刻か確認 |
| 1曲分のメモリ | 動画を全フレーム展開せず必要区間を保持。キャッシュ上限と解放を測定。出力データ全保持の現行方式も再評価 |
| 多重WebGL・コード演出 | 必要な配置だけ稼働。プレビュー解像度と同時演出数を測定し、扱える範囲を明示 |
| 状態を持つ演出の巻き戻し | 時刻から直接描く演出を先行。固定刻み再計算の待ち時間・一致は別途評価 |
| 旧シーケンスの描画共通化 | 既存作品の代表例で以前の表示と比較。保存・UIの共有は避ける |
| 音声出力や保存の失敗 | 無音出力・未保存を成功表示しない。原因と選べる形式／保存先を示し、作業状態を保持 |

長尺・多レイヤーの性能は、実際のMac・ブラウザ・素材で測定します。実装速度、納期、処理が実時間より速いことは約束しません。

## 11. 段階と受入条件

以下は設計の検証段階です。詳細な実装計画や作業開始の承認ではありません。

### 段階1: 約30秒の混合シーンで縦に通す

小さな機能セットで、画像＋1種類のp5系演出、短動画＋文字、再編集可能なUNFOLD、別動画を同じ時間軸へ置きます。主曲・歌詞・効果音、ロック、保存再読込、シーク、音付き書き出しまで含めます。装飾UIだけのデモや無音動画で完了としません。

最低限の検証作品は0〜8秒、8〜14秒、14〜22秒、22〜30秒の4シーン。12〜16秒の歌詞でシーン越境、14秒の効果音で開始同期、短動画の途中トリムで元時間の保持を確かめます。同じUNFOLD設定の2配置を一時的に作り、片方だけ再編集できることも確認します。

### 段階2: 1曲を仕上げられる実用版

段階1の仕組みに、使いやすいシーン／レイヤー編集、工房の見本配置、取り消し、明確なエラーと保存復旧を揃えます。代表的な1曲を最初から最後まで編集・保存・再読込・出力し、資源の使用量と待ち時間を記録。扱える入力形式・同時演出・出力条件を実測に基づき示します。

### 段階3: 実測後の拡張

p5系演出の追加、前フレーム依存演出、対応UNFOLDメソッドの拡大、画面比率や入力形式の追加を個別に検討します。動画元音声の別トラック化など、初期範囲外の機能は新たな設計判断を経ます。

| 受入項目 | 合格条件 |
| --- | --- |
| 位置ロック | ON中の映像移動・挿入・削除・トリム・並べ替え前後で主曲の配置・使用区間、全歌詞IDの開始・終了が完全一致。効果音も変化しない |
| ロックの意味 | 色・文字モーション・主曲音量は変更可能。時間操作と対象削除は拒否。解除したトラックだけ時間編集できる |
| 分割・トリム | 切断の前後で動画・UNFOLD・音の元時間が飛ばない。シーン左トリムで残る内容が動かず、再延長で復元 |
| 並べ替え・削除 | 対象映像だけが規則どおり変化。削除で空き時間を詰めない。衝突移動と空きを含む並べ替えは明示拒否 |
| 歌詞の越境 | 12〜16秒の歌詞が14秒のシーン切替でも途切れず、モーションも再スタートしない |
| 効果音 | 主曲と重なり、配置・トリム・音量・フェードがプレビューと書き出しに反映。動画元音声は鳴らない |
| シークと出力 | 同一解像度の合成前フレームについて、順再生・任意シーク・書き出しで素材時刻、重ね順、歌詞、乱数結果が一致。GPU・圧縮差の完全なバイト一致は要求しない |
| 音声同期 | 合成前音声の効果音開始・終了位置がサンプル単位で一致。圧縮後動画でも検証用の視覚マーカーと音のズレが30fpsの1フレーム以内。曲終端で累積ずれなし |
| UNFOLD独立性 | Bの編集・適用・UndoでAと元作品とライブラリのデータが変化しない。再読込後も保持 |
| Undo/Redo | 複合操作を1回で復元。ロック・設定・素材参照を含め整合。文字入力中Deleteでシーンが消えない |
| 保存分離 | 旧シーケンスの自動保存・新規作成・素材削除後もSTUDIOが再読込可能。逆方向も旧作品が変化しない |
| ファイル往復 | キャッシュのない状態で専用ファイルを開き、必要素材と設定が復元。不足・破損・非対応版は現在作品を壊さない |
| 異常系 | 容量不足、出力非対応、コード演出エラー、中止を成功表示しない。最後の保存と編集状態を保護 |
| 1曲検証 | 曲末尾まで出力・再生確認。複数回のシーク・読込・演出切替後に資源が増え続けない。機材・素材・使用量・待ち時間を記録 |

## 12. ユーザーレビューで確認する重要点

以下は未決定のまま隠さず、具体案として確認します。ここまでの確定要件である位置ロック・効果音・独立したUNFOLD再編集を取り下げる質問ではありません。

1. **初期の出力と入力範囲**：横長16:9・1080p・30fps、MacのChrome、短いH.264 MP4から始める案でよいか。縦MVを最初から必須にする場合は段階1の検証条件も増やす。
2. **動画の元音声**：初期版はミュート固定、効果音は独立ファイルとして入れる案でよいか。動画の会話音等が必須なら初期範囲を見直す。
3. **映像の組み替え**：挿入・削除では時間を詰めず、並べ替えだけ対象区間内の映像を動かす案でよいか。主曲・歌詞・効果音はどちらの場合も動かさない。
