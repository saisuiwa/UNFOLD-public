# 「04 見た目」タブを区間ごとに出し分ける（シーケンス）— 設計

作成日: 2026-10-02（同日、「画像」表示を追加して改訂） ／ 対象: `app/sequence.html`・`app/sequence.js`・`app/style.css`

## 目的

シーケンスの右パネル「04 見た目」には設定が多い。今プレイヘッドがある区間（**ぐちゃぐちゃ／立体化／画像**）で**効かない設定は隠して**、触るべきものだけを見せる。画像を見せている間に触れるのは、主に演出・カメラ・全体設定だけにする。

## やらないこと

- 設定の意味・保存形式・既定値は変えない（`.unfold` の中身は変わらない）。
- 「03 選択中」タブ（◆ごとの上書き）と、1枚モード（`index.html`）は変えない。
- 1つの設定を「区間ごとに別の値にする」機能ではない（値は今まで通り全体で1つ）。

## 3つの表示

プレイヘッドの位置で決まる。画像のクリップをクリックすると、プレイヘッドもそこへ移る（`timeline.js` が選択と同時に `seek` する）ので、「画像を選択した」状態は「画像」表示になる。

| 表示 | 条件 |
|---|---|
| ぐちゃぐちゃ（橙） | `phaseOf(L) === 'chaos'` |
| 立体化（紫） | `phaseOf(L) === 'form'` |
| 画像 | `phaseOf(L) === null`（1枚を見せている間、◆の最初と最後で絵がほぼ元に戻っている間） |

## 項目の振り分け

各項目がどの区間で効くかは `sequence.js` / `motion.js` / `effects.js` の使われ方で確認済み。**区間の欄が空の行は「いつでも」**で、3つの表示すべてに出る。

| 区間の欄（`data-phase`） | 項目（`id` / キー） | 根拠 |
|---|---|---|
| `chaos` | 崩れの強さ `seq-strength`／ぐちゃぐちゃ中の引き `seq-pullback`／粒の細かさ `seq-detail` | `uStrength`、`pullback * (1 - c.form)`、粒の見た目は `distort` 区間 |
| `form` | 立体化中の引き `seq-form-pullback`／プッシュイン `seq-push`／シルエット感度 `seq-sil`／回り込み `cam.orbit` | `formPullback * c.form`、`push * c.form`、`orbit` は `c.form` を掛けて回す |
| `chaos form` | 拍のパルス `seq-pulse`／ボケ `fx.bokeh` | `beatKick` は `c.distort > 0.02` のときだけ。ボケは飛んだかけらがぼけ、ピントは画像の面にある |
| （空＝いつでも） | BPM・1枚を見せる拍数・音楽の開始位置／画面いっぱいに表示／背景色／演出（光のにじみ・ネオン・ネオンの色・**ガラス**・色収差・グリッチ・走査線・ノイズ・周辺減光・ぼかし）／カメラ（遠近感・ゆっくりズーム・手持ち揺れ・傾き）／GLBの一覧 | 全体にかかる。**ガラス**は `glassLook` が全ピクセルに掛かるので、平らな画像にも青みと透け感が乗る |

**画像表示で消える行**は 9 行（`data-phase` が付く行すべて）。残るのは、リズム・画面いっぱい・背景色・演出・カメラ（回り込み以外）・GLB一覧。

## 動き方

1. **判定**：既存の `phaseOf(L)` を使い、`phaseOf(L) ?? 'image'` を表示とする。
2. **表示ルール**：行は「`data-phase` が無い」か「その表示が `data-phase` に含まれる」ときだけ見える。
3. **切り替えのタイミング**：止まっているとき（スクラブ・一時停止・クリックでの移動）に反映する。**再生中は切り替えない**（チカチカ防止）。再生が止まった時点で最新の表示に合わせる。
4. **立体化なしの◆**（`shape === 'none'`）：`phaseOf` が崩れ区間だけを返すので、立体化の項目は出ない。
5. **ドラッグ中**：ポインターが押されているスライダーの行は消さない。離した後に反映する。
6. **逃げ道**：パネル上部に「**自動 / すべて**」の切り替えを置く。「すべて」なら全項目を表示する。既定は「自動」。この選択は保存せず、開き直すと「自動」に戻る。
7. **今どの表示か**を、切り替えの横に一言で示す：「いま：画像／ぐちゃぐちゃ／立体化」。画像表示のときは「◆の区間にプレイヘッドを動かすと、変形の設定が出るよ」と添える。

## 見た目

- 並び順は今のまま。区間のある行の先頭に、既存の丸（`.phase-dot chaos` 橙／`.phase-dot form` 紫）を付ける。「`chaos form`」の行は橙と紫の丸を2つ並べる。丸のない行は「いつでも」。
- `seq-pullback`・`seq-form-pullback` にはすでに丸が付いている。それ以外に追加する。

## 実装の入り口

- 静的な行（`sequence.html`）：`data-phase="chaos"` / `"form"` / `"chaos form"` を付ける。
- 動的な行（`FX_UI` / `CAM_UI` から作る演出・カメラ）：配列に区間の欄を足し、`slider()` が行に `data-phase` を付ける。区間の欄が無い行は「いつでも」。
- 切り替え：`updateTransport` で `phaseOf(L)` を求めている所から、「表示モード」を更新する関数を呼ぶ。隠すのは CSS（`#pane-look[data-view="image"] [data-phase] { display: none }` など、属性で切り替える）。
- `renderFxPanel()` で行を作り直した直後にも、現在の表示モードを再適用する。

## 確認方法

ブラウザで `tools/serve.py` を起動して確認する（右パネルの行の表示を `javascript_tool` で数える）。

1. 起動直後（先頭の画像）→ 「画像」表示：`data-phase` の付く9行が消えている。
2. ぐちゃぐちゃの区間へスクラブ → 立体化の4行が消え、ぐちゃぐちゃ・両方・いつでもが見える。
3. 立体化の区間へスクラブ → ぐちゃぐちゃの3行が消え、立体化・両方・いつでもが見える。
4. 区間の外（画像を見せている間）へスクラブ → 「画像」表示に戻る。
5. 画像のクリップをクリック → プレイヘッドが移り、「画像」表示になる。
6. 再生中 → 表示は変わらず、停止すると最新の表示に合う。
7. 「すべて」→ 全項目が見える。「自動」に戻すと、また絞られる。
8. 立体化なし（`shape === 'none'`）の◆ → 立体化の項目は一度も出ない。
9. スライダーのドラッグ中に区間が変わっても、そのスライダーは消えず、離した後に反映される。
10. 既存の `.unfold` を開いて保存し直しても、設定値が変わらない。
