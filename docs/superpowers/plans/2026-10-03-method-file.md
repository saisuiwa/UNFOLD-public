# 自作メソッド1個をファイルで渡す（`.unfoldmethod`）— 実施記録

2026-10-03。作者の依頼：自作タイルの⚙メニュー（またはエディタの保存の隣）に、自作メソッドをファイルに保存する項目が欲しい。もともとの設計書では「あと回し」にしていた、メソッド単体のファイルを前倒しで作りました。

## 設計（作者の案＋私の判断）

- **形式**：`.unfoldmethod`。小さな読めるテキスト（JSON）。`.unfold` は画像や曲も入る大きなバイナリなので、別名にしました。メモ帳で開けて、AIにも貼れます。
  ```json
  { "format": "unfold-method", "version": 1,
    "methods": [ { "id": "cm-…", "name": "流星群", "symbol": "⭐", "vertex": "…コード…", "look": null, "params": [] } ] }
  ```
  中身は、`.unfold` の中の `methods` と同じ書き方。状態（status）・理由・版番号は持ち出さない。
- **保存**：⚙メニューの「ファイルに保存（.unfoldmethod）」（1枚モード・シーケンス共通）と、エディタ下の「ファイルに保存」（今エディタに出ている内容を、保存前でもそのままファイルにする。コードが空なら「コードが空だよ」）。
- **読み込み**：方法一覧の最後の「ファイルから読み込み」タイル、シーケンスの「読み込み」ボタン（拡張子が `.unfoldmethod` なら、プロジェクトを開かずメソッドとして取り込む）。
- **安全**：取り込みは `.unfold` と同じ。検査（`validateEmbedded`）→コードのハッシュで手元と照合（同じコードは増やさない）→新しいものは「未確認」→「有効にする」で書き方チェック・コンパイル・試し描画。ファイルが「ok」と言っても無視する。
- ファイル選択に `accept` を付けない（Safari などは、知らない拡張子のファイルを選べなくすることがあるため。選んだものは必ず検査する）。

## 確認（2026-10-03）

- 単体テスト 169本が全部通過（＋9：method-file 8、registerQuarantined 1）。
- ブラウザ（実際の作者の「流星群」で）：⚙メニューから保存 → `流星群.unfoldmethod`（1591バイト、`format: unfold-method`、1個、キーは `id,look,name,params,symbol,vertex` だけ）→ 空のブラウザ側で読み込み → 「未確認」でGPUに載らない（コンパイル数 0）・バナー表示 → 同じファイルをもう一度読んでも増えない → 「有効にする」で合格。
- シーケンスの「読み込み」ボタン経由（`accept` は `.unfold,.unfoldmethod`）でも取り込めて、開いていたプロジェクトは変わらない。
- 悪いファイル：JSONでない／別の形式／新しい版／空／id違い＋HTML入りの名前＋`while(true)` の混在、がすべて想定どおり（日本語の理由、または未確認で取り込むだけ。HTMLは文字のまま）。
- エディタのボタン：編集中の名前がそのままファイル名と中身に（レジストリの名前は変わらない）、空なら「コードが空だよ」、新規でも `cm-…` の id が付く。1枚モードにもタイルとメニュー項目が出る。
- 標準の29個は公開版（9/30のZIPと同一）と同じ絵：1枚モード 58/58、シーケンス 117/117 一致。
- ダウンロードは、ブラウザのダウンロードを横取りして確認した（ファイルは作っていない）。実際のダウンロードフォルダへの保存と、Safari での読み込みは、作者の手元での確認待ち。
- Safari での読み込みは、作者が手元で確認済み。
- 気づき：作者は `python3 tools/serve.py`（ポート8771）を自分で起動していて、`app/` をそのまま配信している。つまり、このコードは作者のブラウザを再読み込みするだけで反映される。

## 追加（同日）：エディタの見出しと「コードを消す」

作者の要望：名前の欄とその横の1文字の欄が何を入れる欄か分からない／コードを消すボタンが欲しい。

- 名前の欄に「名前（一覧に出る名前）」、1文字の欄に「アイコン（タイルの1文字）」の見出しを付けた（入力例：「例：流星群」「例：★」。ツールチップに文字数の上限と「絵文字でもOK」）。
- 「コードを消す」ボタンを、「AIに頼むひな形をコピー」の隣に追加。`select()` → `execCommand('delete')` で、普通の入力と同じ消し方にして、ブラウザの元に戻す（⌘Z）が効くようにした（使えないブラウザでは値を空にして `input` を送る）。消すと「コードが空です」と出て保存できなくなる。すでに空なら何もしない。
- 確認（実ブラウザ）：見出しの文言、消す→空・チェックが「コードが空です」、⌘Z（`undo`）で207文字が全部戻る、空のときは何も起きない。単体テスト169本は変わらず通過。
