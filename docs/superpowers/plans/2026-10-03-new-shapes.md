# 新しい立体の形（龍・クジラ・鳥の群れ・球の群れ）と、人・ペガサスの作り直し — 実施記録

2026-10-03。作者の依頼：ドーナツが真横からばかり見えて分かりにくい／ペガサスと人の形を作り直す／龍やクジラを足す／鳥が何羽も散らばる立体化や、16:9 に合った数の球がたくさん並ぶ立体化も欲しい。

## しくみ（それまで）

- 組み込みの形（球・ドーナツ・らせん…）は計算式、りんご・アイス・人・ペガサスは「楕円体のパーツを組み合わせたもの」（`app/shape-presets.js` の recipes）。画像は 16×16 のタイルに分けて、パーツの表面の「パッチ」に1枚ずつ貼る。貼る順番は決まった並べ替え（`(tile*73+19)%256`）で、元の絵の並びがわからなくなる。

## 変えたこと

- **位置どおり貼る** `OPTS[name].ordered`：パッチの中心を、y（下から上）で256個を16段に分け、各段を x（左から右）に並べて、タイル番号（下の段から、左から右）に順に割り当てる。形の左が絵の左、下が下になり、絵が形に印刷されたように見える。新しい形（人・ペガサス・クジラ・龍・鳥・球）だけ。りんご・アイスは今までのまま。
- パーツごとのタイル数の最小 `min`（球の群れは144個なので1枚、龍・クジラも1枚）。残りは均等にばらまく（`ordered` のときだけ。今までの形は今までの配り方）。
- `fit(parts, w, h)`：形全体を、ゆがませずに、決めた幅・高さに収めて、真ん中を原点に置く。人・ペガサス・クジラ・龍・鳥に使う（画面は 5.25×2.95）。
- 新しい形：
  - **クジラ**（右向き）：胴・頭・下あご・おなか、尾（V字に立てる）、背びれ、胸びれ、潮ふき。
  - **龍**（東洋の龍）：S字の胴（20個の楕円体、太→細）、角と髭のある大きな頭、たてがみ、4本の足（爪つき）、背中のとげ、尾の先。
  - **鳥の群れ**：14羽（5＋4＋5）、こちらに向かって飛ぶ。翼を打つ瞬間が1羽ずつ違う。
  - **球の群れ**：16×9＝144個。幅/高さ＝16/9。ゆるやかな波（奥行き）。
- 作り直し：**人**（8頭身に近いA字ポーズ。以前は頭が大きすぎた）、**ペガサス**（走る馬＋肩から広がる大きな羽根、羽は幅広い8枚）。
- 画面：形のボタンの名前とアイコン（クジラ「鯨」、龍「龍」、鳥の群れ「鳥」、球の群れ「⁘」）。
- 版番号：`shape-presets.js?v=6`、`sequence.js?v=57`、`app.js?v=47`（`index.html`）。

## ドーナツが分かりにくい件

- ドーナツ（トーラス）は、寝かせた形で、◆の「縦向き」が 0 のまま（−9°）だと真横から見るので穴が見えない。動画では、◆ごとに縦向きを 0.95（約54°）にして、上から見下ろす向きにした（穴が見える）。
- 画面の「縦向き」スライダー（◆のパネル）か、立体をドラッグして、いつでも変えられる。初期値を変えると、今までの保存ファイルの見た目も変わるため、そのままにした。
