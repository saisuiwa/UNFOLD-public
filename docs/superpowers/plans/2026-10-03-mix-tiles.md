# ◆ごとの「絵柄を混ぜる」オン／オフ — 実施記録

2026-10-03。解説動画のX版を作る中で、作者から質問があった：地球が球になる瞬間に、本物の地球らしくなると思っていた。地図ではなく、透過PNGの丸い地球ならどうなるか。

## 原因と検証

- 球がタイルのモザイクになるのは、**変形の途中で画像のタイルを意図的にシャッフルしている**から（`uConceal`。元の絵を隠す演出。シーケンスでは `curves()` の `conceal` で常にオン）。球への貼り方そのもの（横＝経度、縦＝緯度）は正しく、世界地図（正距円筒図法）をそのまま貼れば地球儀になる。
- 1枚モードには、このシャッフルを切るチェック「絵柄を混ぜて、最後に見せる」が既にあった。シーケンスには無かった。
- 実際に4パターンを並べて確認（1枚モード、球、同じ時点）：
  1. 世界地図＋混ぜるオン（これまで）→ タイルのモザイクの球
  2. **世界地図＋混ぜるオフ → 本物の地球儀**（アフリカ・大西洋・南アメリカがそのまま）
  3. 丸い地球（透過PNG）＋オフ → 正面は地球に見えるが、球の裏側は透明部分で真っ黒
  4. 丸い地球（透過PNG）＋オン → 黒い隙間だらけの壊れたモザイク
- 結論：丸い地球の画像より、**世界地図の画像で「混ぜる」を切る**のが正解。

## 設計・実装

- ◆に `mixTiles`（`false` のときだけ混ぜない。ない／それ以外は今までどおり混ぜる）。
- 描画：`u.uConceal.value = concealAmount(tr, c.conceal)`（`app/fx-mix.js`。純粋な関数）。
- ◆のパネル（03 選択中）に「絵柄を混ぜる」チェック（初期値オン）。オフにすると `tr.mixTiles = false`、オンに戻すと項目ごと消す。元に戻す（⌘Z）に対応。
- ファイル／自動保存の読み込み：`withCleanFx` で、`mixTiles` は本物の `false` だけ残す（文字の `'false'` などは捨てる）。
- 版番号：`sequence.js?v=51`。

## 確認（2026-10-03）

- 単体テスト 179本が全部通過（`concealAmount` の1本を追加）。
- **変更前の版との直接比較**（同じタブ）：標準29個×4時点＋ミックス＝117点が**全部一致**＝初期値のままなら今までと同じ絵。
- オフの効き方：◆の0.01と0.99では同じ、0.1〜0.9では違う（混ぜる曲線 .03〜.97 の範囲）。項目を消すと、元と完全に同じ（7時点）。
- パネル：チェックがあり、初期値オン、オフにすると保存され、⌘Zで戻る。保存ファイルの `mixTiles: false` が、読み込みで戻る。文字の `'false'` は捨てられる。
- これを使って、X版を作り直した（`video/出力/X版_案2_声なし.mp4`）。りんごの皮の球 → **本物の地球**、ドーナツ形に地図が貼られてからスプリンクル柄に変わる、が出ている。りんご形（プリセット）は、形の作り方のためにタイルの並びが元々かき混ぜられるので、モザイクのまま。
