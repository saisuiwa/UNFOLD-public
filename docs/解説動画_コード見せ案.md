# 解説動画：「メソッドはコードでできている」パート案（2026-10-02）

週末に作る UNFOLD 解説動画の中に入れる「しくみ」パートの案。
画面に映すコードは **`app/motion.js` の実物をそのまま使う**（作り物のコードは映さない）。

## 見せたい一言

> 1つの崩れ方 ＝ 数行の数式。画像を細かいタイルに割って、GPUが毎フレーム全部のタイルの位置を計算している。

## 素材（すべて実物）

| 見せるもの | 出どころ |
|---|---|
| 崩れ方の全コード（29個の枝・約215行） | `app/motion.js` の `breakAt()`（29行目〜） |

## シーン案（合計 約25秒・横16:9 想定）

### ① 29の枝（約4秒）— インパクト
`breakAt()` の約215行を高速スクロール。`// vortex:` `// melt:` `// galaxy:` などのコメント行が流れるたび、その名前がパッと光る。
- ナレ案：「UNFOLDの崩れ方は、全部コードでできています。」

### ② 画像をタイルに割る（約6秒）— 共通のしくみ
画像に16×16のグリッドが重なり、タイルごとに違う色の「ランダムな値（`hash()`）」が浮かぶ。
- ナレ案：「画像を細かいタイルに割って、タイルごとに違う動きを数式で決めています。」
- 注意：これは説明用の図解（アプリの画面ではない）と分かるようにする。

### ③ 渦に吸い込み：コードと動きを並べる（約10秒）— 主役
左にコード4行、右にUNFOLDで渦が回る画面。コードの行が1行ずつ光り、同時に動きが変わる。
```glsl
float r=length(p);
q=rot(amount*3.4/(r+.35))*p*(1.-amount*.6*exp(-r*.5));
qz=-amount*.9*exp(-r*r*.7);
```
- 1行目：「中心からの距離を測って」
- 2行目：「中心に近いほど強く回して、中心へ縮める」
- 3行目：「奥へも沈める」
- ナレ案：「たったこれだけで、渦に吸い込まれるように見えます。」

### ④ 数字を変えると別物になる（約5秒）— 余韻（任意）
`3.4` を `8.0` にして、同じ渦の巻き方が変わる様子を比較（左：3.4／右：8.0）。
- 実際に書き換えた版をUNFOLDで書き出して撮る（ローカルで `app/` のコピーを使う）。アプリ内エディタの画面ではないので、「数字を変えると変わる」という見せ方にとどめる。
- 「自分で追加できる」機能（別ファイル参照）を作ってから撮れば、アプリ内で実際に書き換える画面にできる。

## 作り方

- コード画面は **HTMLで作る**（シンタックスハイライト、行ごとの点灯、スクロール）。HyperFrames系のスキルが使える。
- 右側の動きは UNFOLD の MP4 書き出し（画質「高画質」）をそのまま貼る。
- コードは必ず `motion.js` からコピーして使う。書き写しミスで嘘のコードを映さないため。

## 画面の向きで変わること

- **横16:9**：コードがそのまま読める。上のシーン案のまま。
- **縦9:16**：コードの横幅が足りない。③は3〜4行を大きい文字で出し、①は読ませずに「流れる雰囲気」だけにする。
