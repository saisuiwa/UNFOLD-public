# UNFOLD 歌詞MV：文字モーション調査・構成案

2026-10-04 / 調査・独立した構成試作。本体への組込みは未実施。

## 結論

今の「一つの歌詞ブロックを動かす」描画から、「語句・文字・図形を一つの画面として構成し、時刻から描く」方式へ広げる。既存の Canvas2D → CanvasTexture → 最前面合成を再利用できる。新しい映像制作ライブラリや外部AIサービスを入れる必要はない。

高品質化の中心は演出数ではなく、(1)語句の大小と配置、(2)登場順と緩急、(3)読む時間の確保、(4)前後の行のつながり、(5)曲全体の統一感。画像の立体化に対して歌詞は平面のモーショングラフィックとして扱う。

各6秒の無音見本。再生、一時停止、シーク、読ませる瞬間への移動、暗い/明るい/動く背景、動きの強さ、6案の連続再生。歌声同期・任意歌詞の入力・本体への保存・動画書き出しは比較ページの対象外。

「もっと種類」は色違いではなく、構図・視線の移動・時間配分が違うものとして増やす。試作の6案を完成プリセットと扱わず、実際の曲に合わせて絞り込み・調整する。

## 使いやすさの推奨構成

今の「曲 → 歌詞 → 雰囲気 → タイミング」を維持。

1. 雰囲気は「落ち着いた / ポップ / 大胆」の3入口。各入口が複数の構成を持つ。
2. 「曲全体にお任せ」で区間タグ、尺、文字量、強調語から構成を割り当てる。色・書体は曲全体で共通、同じ構図の連続を抑制する。
3. 行を選ぶと動く構成カードから交換。「この行だけ別案」「固定」を置く。固定済みの行と手動タイミングは再生成でも保持。
4. 普段見せる調整は「動きの強さ」「主役の言葉」「配置」程度。単語ごとの座標やキーフレーム編集は最初から要求しない。
5. タイミングがない歌詞には仮の配分を使い、「歌声に合わせた確定同期」と区別する。MP3の歌詞タグや曲の区間名だけで歌唱時刻を正確に復元できるとは扱わない。

### 区間タグの扱い

`[Intro]` / `【イントロ】` は導入向け、`[Verse]` は読みやすさ優先、`[Chorus]` は強い階層と大きな語、`[Bridge]` は構成変化、`[Outro]` は余韻の初期候補を与える。タグ自体は通常歌詞に描画しない。区間名は演出候補の手掛かりであり、BPM・拍位置・強弱の確定情報ではない。

## 本体実装の境界

- `lyric-motion.js` は現在5種、1ブロックの移動/拡大/表示率が中心。ここへ構成の定義と語句/文字ノードの時刻評価を追加する。
- `lyric-overlay.js` の既存Canvas合成を再利用。レイアウト計算は歌詞/書体/サイズ変更時にキャッシュし、フレームごとは位置・不透明度などを評価する。
- `compileScene(event, layoutContext)` → ノード列 → `evaluateScene(scene, absoluteTime)` → Canvas描画。毎フレーム増分で位置を変えず、シーク・再生・書き出しで同じ時刻の絵を一致させる。
- 明示された `/` 改行、`*強調*`、既存の `words` 時刻があれば優先。時刻付き単語とテキストが一致しない場合は安全に行単位へ戻す。日本語の自動語分割は補助に留め、ユーザーが主役の語を直せるようにする。
- 旧データは従来5種の見た目を維持して読み込む。新構成用の識別子を増やし、正規化・保存・復元・Undo/Redoまで一緒に対応する。
- 次行へのつながりには前後イベントの情報が必要。現在の `activeLyric` は1行だけのため、移行時だけ両行を描く設計か、単一行内で完結する退場のどちらかを明示して実装する。
- 歌詞は最前面の平面合成という現在の方針を維持。画像に遮られる3D歌詞、立体の後ろへの回り込みは対象外。
- 動く画像背景での読みやすさは、帯・影・局所的な暗幕から構成に合うものを使う。全画面を常に暗くする方式は本体にそのまま適用しない。

## 品質の合格条件

1. 同じ行の開始直後だけでなく、中盤と退場にも意図がある。読ませる区間には主役の文字を過剰に揺らさない。
2. 短い行に長い登場を押し込まない。尺が足りなければ文字ごとの時間差を減らし、一括表示へ簡略化する。
3. 長い日本語、句読点、英字、絵文字、複数行、縦書きを確認。サイズを縮め続けて読めなくする前に構成を切り替える。
4. 画像背景の暗い/明るい/動きの大きい場面で読みやすい。意図した巨大な装飾文字を除き、安全域からはみ出さない。
5. 同じ絶対時刻を順送り・逆シーク・書き出しで比較して一致。30/60fpsの差で動きが変わらない。
6. 曲全体へのお任せ、1行の交換、固定、Undo/Redo、保存後の再読込で歌詞やタイミングを失わない。
7. 最終的には参考曲のAメロ・サビ・ブリッジ各10〜15秒を本体で書き出し、実音と合わせてレビューする。この試作だけで最終品質を合格としない。

## 次の実装単位

まず「余白」「大きな言葉」「縦の詩」の3系統を、本体の保存・タイミング・書き出しまで通す。その同じ仕組みで「響き」「集合」「一文字」を追加する。全曲の演出配分は最後に調整する。画像描画器とメディア読込は作り直さない。
