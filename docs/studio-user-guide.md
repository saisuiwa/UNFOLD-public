# STUDIOの使い方

[公開STUDIO](https://unfold.saisuiwa.com/studio) を開きます。ローカルではリポジトリのルートで `python3 tools/serve.py` を実行し、`http://127.0.0.1:8771/studio.html` を開きます。シーケンスの「06 STUDIO」から進むこともできます。Mac Chromeで検証しています。

**かんたん / 詳細** 画面上の「かんたん / 詳細」で表示を切り替えます（選んだ状態はこのブラウザに残ります。最初は「かんたん」）。「かんたん」では、シーケンスから送った作品を仕上げるのに必要なもの（おまかせ・歌詞の編集・画像や文字や効果音の追加・保存・MP4書き出し）だけを出します。曲や歌詞を直接入れる、UNFOLD作品を置く、ファイル保存、分割・複製、ショート、位置固定、数値での配置などは「詳細」にあります。下の手順1〜8の多くは「詳細」の操作です。

**おまかせ** 「おまかせ」は歌詞の動き・背景・配色・大きさをまとめて決めます。「配色の系統」で白＋アクセント・ネオン・パステル・モノクロ・暖色・寒色・ロック（赤）・ゴールドから色の雰囲気を選べます（「雰囲気におまかせ」なら雰囲気ごとに決まります）。気に入らない所だけ「ここだけ変える」で引き直せます。

1. 「主曲を読み込む」で曲を置きます。最初の主曲の長さが作品の長さになります。曲より後ろに既存の配置がある場合は、先に区間を整理してください。
2. 「＋画像・動画」「文字を追加」「光の演出を追加」で素材を重ねます。動画は元音声を使うかミュートするか選びます。空き時間ではシーンも作られます。
3. 「歌詞を入力・同期」は歌詞の位置固定を解除してから使います。入力後は仮タイミング、時刻付き入力、曲を聴きながらのタップ同期を選べます。編集後は位置固定を戻せます。
4. タイムラインは選択したシーンのレイヤーだけを展開します。曲・歌詞・音声と共通の時間目盛りを使い、横縦の切替やズームでも時刻は同じです。明示的にシーンや配置を選ぶと編集対象を保持し、再生中のシーンは金色の線で別に示します。未選択時は再生位置のシーンを表示します。配置を選び、中央をドラッグして移動、端をドラッグしてトリムします。「再生位置で分割」「配置を複製」「選択を削除」とUndo/Redoも使えます。動画元音声のリンク中は映像と一緒に動きます。
5. 右欄の「共通の内容」で時間・素材・音量・フェードなど、「この版の配置」で位置・大きさ・回転・画像の収め方・文字幅などを調整します。横と縦は同じ時間軸を共有し、構図だけ独立しています。
6. 工房の「見本を配置」は名前と設定をコピーします。UNFOLD配置を選んで編集フォームを開き、プレビュー後に適用または取消できます。他の配置には波及しません。
7. 「ショートを追加」で連続した開始・終了区間を設定します。内部の演出時刻は全曲の時刻のままです。縦を選び、構図を調整して区間を書き出します。
8. 「ブラウザに保存」と持ち運び用の「ファイル保存」を使えます。既存素材の整理は保存と別処理です。別タブが編集権限を取得すると読取専用になります。再読み込み時も古い編集権限が残って読取専用になる場合があります。その場合や未保存編集があるときは「このタブで編集」で権限を戻し、保存してから作品を切り替えてください。

音付きMP4はH.264/AAC、30fps、横1920×1080・縦1080×1920です。既定ではショート境界のフェードはOFFです。外部コードを含む作品は提供元を確認して許可してください。

現在の対応範囲：p5は同梱の時刻指定演出1種。UNFOLDの文字形状・シルエット形状は理由を示して未対応とします。縦版のUNFOLDは横構図を収め、配置・拡大率・背景を調整します。実曲、iPhone、他ブラウザの検証結果は含みません。詳しい実測は `studio-validation.md` を参照してください。
