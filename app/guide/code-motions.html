自分の動きを、UNFOLDに。

歌詞を選択し「動き → ＋追加・コードで作る」を開きます。ひな形を選んでプレビューし、「追加してこの歌詞に使う」でブロックが増えます。コードを変えて別の名前で追加すれば、動きを増やせます。

JavaScriptでThree.js・Troika Text・GSAPを組み合わせます。既存のWebページを丸ごと取り込む形式ではなく、下の共通APIに合わせたコードを使います。従来のレシピもそのまま利用できます。

コードの形

使えるAPI
名前内容

scene / camera文字用の透明なシーン・平行投影カメラ。画面中心が原点、xは右、yは上、単位はpx。
text / runs改行・強調記号を処理した歌詞と、text・emphasis・colorを持つ部分の配列。
width / height / fontSize出力サイズと選択した文字サイズ。固定解像度に依存しないよう、この値から配置します。
color / accent / fontURL歌詞の文字色・強調色・選択した書体のローカルURL。
createText(text, options)選択した書体と色のTroika Textを作りsceneに追加。歌詞全文なら言葉ごとの色も引き継ぎます。maxWidth、textAlign、outlineWidth等を指定できます。
duration / bpm / random()歌詞の表示秒数・BPM・同じ種からの乱数。乱数は作成時に使い、フレームごとに進めないでください。
同じ時刻は、同じ絵に
return {timeline, update(t), dispose()} のtimelineかupdateが必須です。GSAPはpaused:trueで作成します。UNFOLDが歌詞開始からの時刻tへ移動し、update(t)を呼びます。表示速度を変えるとtとdurationが同じ倍率になります。
update内の位置は「+=」で積み重ねず、時刻から直接求めます。Date.now、setInterval、自動再生、フレームごとのMath.randomは使わないでください。物体や文字は作成時に作り、updateで使い回します。これで再生・巻き戻し・動画出力の見た目を揃えられます。
保存・共有・フォント
追加したブロックはこのブラウザに残り、歌詞に使ったコードはプロジェクトにも入ります。「共有ファイルに書き出す」で .unfoldmotion ファイルを渡せます。受け取った人は読み込み後にプレビューして有効にします。歌詞・曲・画像・フォントのデータは共有ファイルに含みません。
標準6書体はローカルに同梱。PCフォントは「PCのフォント」から選ぶと文字データをブラウザ内に保存します。別PCでは同じフォントを再指定してください。コードモーションではTTF・OTF・WOFFを使用できます。WOFF2はこの描画器では未対応です。
実行環境
ChromeのローカルWebサーバーまたはHTTPSで利用します。モーションは隔離したWorker内で動き、DOM・ストレージ・外部通信は使えません。外部import・画像URL・追加のGSAPプラグインを前提にしないでください。コードは32000文字以内。初期化・描画が一定時間内に終わらない場合は停止してエラーを表示します。
メッシュの表現も追加できますが、UNFOLDの背景とは別の透明な文字レイヤーです。背景の立体モデルと奥行きで交差する構造ではありません。
