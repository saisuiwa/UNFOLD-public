メソッド集

絵が崩れる動き（メソッド）は、標準で 37種類。どれも同じ2枚の絵（港の油絵 → ネオンの街）で動かした見本です。カードにマウスを載せる（スマホはタップ）と動きます。

使うときは、1枚モードの「ぐちゃぐちゃにする」、またはシーケンスの◆を選んだ「崩れ方」から選びます。立体になる前の、崩れていく部分の動きです。

CUSTOM自作メソッドを作る

メソッド一覧の最後の「＋自作メソッド」で、自分の崩れ方を作れます。書くのは短い GLSL のコードだけ。p（絵の中の位置）と amount（崩れ具合：0 で元の絵、大きいほどよく崩れる）を受け取って、動かした位置を返します。

  • 左にコード、右にプレビュー。書き方のチェックと試し描画つき
  • サンプルから始められます。「AIに頼むひな形をコピー」で、チャットAIに作ってもらうこともできます
  • 危ない書き方は保存前に止まり、重すぎると自動で止まります
  • 作ったメソッドは .unfoldmethod ファイルにして人に渡せます（受け取った人は確認してから有効にします）

例：渦に吸い込む（標準のサンプルより）

// 中心に近いほど強く回して、中心へ縮める
vec3 userMethod(vec2 p, float amount) {
  float r = length(p);
  vec2 q = rot(amount * 3.4 / (r + .35)) * p
         * (1. - amount * .6 * exp(-r * .5));
  return vec3(q, -amount * .9 * exp(-r * r * .7));
}
