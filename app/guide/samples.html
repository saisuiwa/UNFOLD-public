サンプル集

自作メソッド（GLSL・JavaScriptの画像メソッド）と、歌詞の文字の動き（コードモーション・かんたん設定）のサンプルです。毎日少しずつ増えます（いまは 35個、最後に増えたのは 10/10）。カードにマウスを載せる（スマホはタップ）と動きます。

崩れ方・グラフィック（GLSL）：「1枚モード」の「ぐちゃぐちゃにする」か、シーケンスの崩れ方の最後にある「＋自作メソッド」を開き、「GLSLで作る」を選んで、「プリセット…」から選ぶとコードが入ります。
画像・立体・物理（JavaScript）と文字モーション（コード）：メソッド工房のサンプルブロックから選びます。コードを書き換えて、自分のメソッドとして追加できます。
文字の動き（かんたん設定）：シーケンスの「05 歌詞・曲」で歌詞の行を開き、「動き」から選びます。

// 時計の針が一周するあいだに、針に触れた粒から外へはじき飛ばされる
vec3 userMethod(vec2 p, float amount) {
  vec2 c = partC(), l = p - c;
  float turn = atan(c.x, c.y) / 6.2832 + .5;               // 0〜1 = 真上から時計回りに一周
  float delay = turn * .4 + ph(1.) * .06;
  float e = smoothstep(delay, delay + .25, amount);
  vec2 away = normalize(c + vec2(.0001)) * e * e * (.6 + ph(2.) * .8) * uSize.y;   // 中心から外へ
  l = rot((ph(3.) - .5) * 8. * e) * l * (1. - .3 * e);
  gKind = 2.;                                              // 粒の見た目: 2 = 丸い点
  gAlpha = 1. - .3 * e;
  gLocal = 1.;
  return vec3(c + l + away, (ph(4.) - .5) * .3 * e);
}
