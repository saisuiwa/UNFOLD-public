# UNFOLD

> UNFOLD のソースには、非公開の本体リポジトリ（作業用）と、それを写した公開用リポジトリがあります。文書や記録に出てくるコミット番号（`780034d` など）は本体の番号で、公開用リポジトリでは番号が違います（`docs/公開用リポジトリへの反映.md`）。
>
> ライセンス：MIT（`LICENSE`）。改変や、ほかのアプリへの組み込みも自由ですが、無保証です。`app/vendor/` の同梱ライブラリとフォント（three.js・troika・GSAP・Rapier・p5.js・Mediabunny・各書体など）と、それらを束ねた `app/vendor/*-worker.js` は、それぞれのライセンス（同じフォルダの `*-LICENSE.txt`・`*-NOTICE.txt`）に従います。

## 2026-10-17（続き）：1枚モードにも「ぐちゃぐちゃの長さ」

- **1枚モードの「02 ぐちゃぐちゃにする」に「ぐちゃぐちゃの長さ」スライダー**（シーケンスと同じ考え方、`motion.js` の `motionAt(t, hold)`・`warpTime`・`chaosTime`）。立体化の始まりが、0%で今までどおり（変化の32%）、100%で66%まで後ろへ。電撃で消失・焦げ穴と炎などの表面の効果（変化の約64%まで進む）が、最後まで進んでから立体になります。初期値は50%（立体化は約40%から）。チャプターのボタン・書き出しの「ぐちゃぐちゃから」「立体化から」も、この設定に合わせた位置になります。
- **画像メソッドの描画器（`vendor/image-method-worker.js`、約5MB）の読み込み**：通信エラー（Failed to fetch）なら2回まで自動で読み直し、それでもだめなら「通信エラー」と分かる言葉で知らせます（`image-method-runtime.js`）。

## 2026-10-17：GLBを100 MBまで、テクスチャの色も取り込み、色つきの標準の形（公開済み・`009e487`、[公開記録](docs/publication-colour-shapes-2026-10-17.md)）

- **GLBの上限を50 MB → 100 MB**（1枚モード・シーケンス・GLB置き場）。三角形100万枚までは変わりません。
- **GLBの色を取り込む**：基本色（baseColorFactor）×ベースカラーテクスチャ×頂点カラーを、角（頂点）ごとの色として読みます（`app/model-import.js` の `modelPaint`、`importModel(buf,{colors:true})`）。テクスチャはGLBに埋め込まれた画像だけを読み、外部URLは今までどおり読みません。色は頂点ごとなので、面の少ないモデルではテクスチャの細かい模様はぼけます。KTX2（basisu）だけのテクスチャは読めず、基本色だけになります。
- **「GLBの色（写真と混ぜる）」スライダー**：1枚モードは「粒の細かさ」の下、シーケンスは見た目の設定（`seq.modelColor`、保存されます）。立体になるにつれて写真とGLBの色を混ぜます（平らな写真は染めない）。新しい作品は100%、この設定を保存していない前の作品は0%（写真だけ）で開きます。色のないGLB・組み込みの形・立体文字には効きません。
- **色つきの標準の形 17種**（1枚モードの「03 立体にする」の形ボタン、シーケンスの形メニュー、STUDIO）：カラー見本・スイカ・ドーナツ・土星・アイス・雪だるま・太陽系・積み木・星くず・ルービック・風船・宝石・DNA・マカロン・ドミノ・紙吹雪・ハート吹雪。名前と記号がその形の色で表示されます（青枠なし）。一覧と読み込みは `app/colour-shapes.js`（id は `c-…`、GLB は `app/assets/models/`、最初に選んだときに読む）。GLBは `tools/make_colour_samples.py`（カラー見本だけ `tools/make_colour_sample_glb.py`）で作り直せます。使わなかった案（地球・きのこ・桜吹雪・シャボン玉・星空）も同じスクリプトにあります。
- **画面いっぱいのGLB**：GLBの `asset.extras.unfold.fit = "frame"` があると、いつもの大きさ（長い辺3.5）ではなく16:9の画面（5.25×2.95）に合わせます（`model-import.js` の `fitFrame`）。紙吹雪・ハート吹雪はこれで、立体化中の引きもかけません（`fillsFrame`）。
- しくみ：`model-layout.js` が分割しても色を運び `color`（rgba、a=2が「色あり」）を返す → `modelColor` 属性 → `motion.js` で `uModelColor` 分だけ混ぜる。

## 2026-10-15：シーケンスの操作まわり（拡大・移動／見た目の変形／GLB追加欄）

- **タイムラインに「拡大」「移動」スライダー**（シーケンス）：STUDIOのタイムラインと同じ2本。拡大は「全体」を×1として×8まで、移動は横スクロール位置（拡大しているときだけ動かせます）。「－」「＋」「全体」ボタンやスクロールとも連動します。
- **04 見た目の一番下に「変形」パネル**：再生位置にある◆（変形）の「崩れ方・戻り方・立体化する・形（GLBのタブと絞り込み付き）・向き・長さ・演出」を、見た目タブのままで変えられます（「03 選択中」で◆を選んだときと同じ内容）。ぐちゃぐちゃ／立体化の区間で出ます。止まっている画像の上では、「すべて」にしたときだけ◆の設定が出ます。
- **「追加した立体の形（GLB）」を、動画保存タブへ移動**し、タブ名を「**動画保存・GLB追加**」に変更。GLBの追加・グループ分け・削除はそこで行い、選ぶのは見た目タブ（または選択中タブ）の変形パネルの「形」です。

## 2026-10-15：シーケンスの「ぐちゃぐちゃの長さ」

- **04 見た目に「ぐちゃぐちゃの長さ」スライダーを追加**（シーケンス）：立体化が始まるまでの、ぐちゃぐちゃの時間を長くします。これまでは、崩れの途中（崩れの強さが最大になる前）で立体化が始まっていました。右に動かすほど、崩れきってから立体になります。変化全体の長さ（拍数）は変わらず、立体の部分（立体化・絵の入れ替わり・回転・戻り）が後ろに寄ります。
- 50%を超えると、立体化の始まりをさらに後ろへ（100%で変化の65%あたりから）。焦げ穴と炎のように、画面全体を燃やしきるのに時間がかかる崩れも、燃えきってから立体になります。
- 新しいシーケンスの初期値は **50%**。0% は今までと同じ動き。この設定を保存していない前の作品は、これまでの動き（0%）のまま開きます。書き出した動画にも反映されます。立体化なし（通り抜け・吹き飛ばし・行って戻る）には関係しません。

## 2026-10-14（続き）：言葉の大きさボタン、カラフルなサンプル画像、保存した動きもおまかせへ

- **「選んだ言葉の大きさ」ボタン**（STUDIO、歌詞を選んで「色」タブ）：言葉を選んで「大きく」「小さく」（押すたびに1.25倍・0.8倍、0.4〜2.5倍の範囲）「ふつう」。色や縁取りを変えても大きさは残ります。
- **おまかせの候補が広がりました**：雰囲気ごとの動きに加えて、あとから足された標準の文字モーション（雰囲気に入っていないもの）と、「モーション集」で保存した動き（コードでも一文字ずつ等でも。エフェクトは除く）も使います。「保存した動き・新しい動きも使う」で切れます。保存した動きのコードは、STUDIOがまだ実行を許可していないものがあれば、おまかせで使う前に一度だけ確認します（「キャンセル」なら使わず、勝手に許可はしません）。保存した動きの大きさは測っていないので、位置は控えめに（真ん中寄りに）なります。
- **シーケンスの最初のサンプル画像**（ONE〜FOUR）を、単色の格子から、夕焼け・タータンチェック・海と魚・ポップな図形のカラフルな絵に差し替えました（毎回同じ絵）。

## 2026-10-14 の追加：おまかせの配置と語の大小、装飾つき文字モーション16種、画像系の標準メソッド18種

- **おまかせが、文字を真ん中だけに置かなくなりました**（STUDIO、右の「おまかせ」）：歌詞1行ごとに、左上・右下・上・下・端などへ置き、少し傾け、短い行は横向きにも。置いても画面の外へ出ないよう、動きごとに実測した大きさ（`app/studio/omakase-extents.js`）で収めます。「文字の配置」で「真ん中に揃える」に戻せ、「ここだけ変える」に「配置・大小」を足しました。
- **語ごとの大きさ**：「私」大きい「は」小さい「元気」大きい「です」小さい、のように内容語を大きく、助詞を小さく（`Intl.Segmenter` で語に分け、平均の大きさは変えないので行の幅は同じ）。run の `scale` として保存され、色・縁取り・中抜きを変えても残ります。文字モーション側は語ごとのメッシュ（`textStart`）にもそのまま効きます（コードモーションの描画器を作り直し、`?v=7`）。
- **文字モーション16種**：切り貼り文字の系統（装飾が付く）＝付箋に書く・ラベルライターで打つ・スタンプでドン・蛍光ペンで線を引く・チケットの半券・ぺたっと貼るステッカー・ぽこぽこ膨らむ吹き出し・手描きの丸囲みと下線・黒板にチョークで書く・くるっと回るワッペン。配置の系統＝縦書きが右から並ぶ・左上から階段に並ぶ語・四隅に語を置く・縦と横が交差する・大小が拍で跳ねる・斜めに流れる行。どれもおまかせの雰囲気に入っています（配置の6種は自分で位置と大小を決めるので、おまかせは動かしません）。
- **画像系の標準メソッド18種**（63 METHODS）：タイルが落ちて跳ねる・爆発して元へ戻る・画像片と文字がぶつかる・渦に巻かれるタイル・爆砕と再誕・波紋で傾くタイル・ドミノのように倒れる・とろけて垂れるタイル、金継ぎ陶片・水滴レンズ・織り写真・銀箔うねり、立体ポップ・砂になって落ちる・ストライプスライド・斜めに掃き飛ばす・カーテンが開く・針のように掃く。1枚モードとシーケンスの最初から選べます（工房で「追加」する必要はありません）。

## かんたん歌詞・曲（2026-10-04）

シーケンスの「05 歌詞・曲」で、既存の画像・立体映像の前面にテキストモーションを重ねられます。

1. 曲を選ぶかドロップ。MP3（ID3 USLT/SYLT、v2.2 ULT/SLT）とM4A/MP4（©lyr）の埋め込み歌詞をローカルで読みます。入力済みの歌詞は候補ボタンを押すまで置き換えません。
2. 歌詞を貼り付けるかLRC/JSON/TXTを選択。[Chorus]・【サビ】などは演出の区分になり、見出し自体は動画に出ません。未知の見出しや間奏に続く文章は、歌詞か指示かを選べます。/ は画面内改行、*言葉* は強調。
3. 「読みやすく」「元気に」「やわらかく」を選び再生。各行を開いて色・書体・位置・動き・時刻を変更できます。「この動きを固定」で、おまかせの変更からその行を守れます。
4. 時刻のない歌詞は仮配置です。「タップで合わせる」で歌い出しと間奏開始を記録し、途中停止・再開できます。文字入力中のSpaceはタップを発火しません。音声認識による自動文字起こしや歌唱位置の自動推定は行いません。
5. 動画保存タブでMP4（H.264/AAC）またはWebMを保存。曲尺が基本で、背景が短い場合は最後の画像を保ちます。音楽の開始位置は既存のoffsetと共通です。

文字のタイミングを変えても、背景の画像・変形・回転・カメラは組み直しません。現在の文字は前面の2Dレイヤーです。立体の背後への回り込みは含みません。

新しい歌詞を含む `.unfold` はversion 3です。旧版UNFOLDでは新歌詞を再現できないため、この版以降で開いてください。version 1/2の旧作品は従来の見た目で開きます。旧歌詞MVは「テキストモーション版を作る」で変換でき、元の保存先を解除して別名保存を案内します。Undoにも対応。

音楽・歌詞・画像を外部サービスへ送信しません。FLAC/Vorbis等の歌詞タグ抽出は対象外です。フォントは既存のWebフォント設定を使用し、オフラインではシステムフォントへフォールバックします。

検証と見本動画：[歌詞MV検証記録](docs/verification-lyric-motion-2026-10-04/REPORT.md)。起動は従来どおり `python3 tools/serve.py`、[ローカルシーケンス](http://127.0.0.1:8771/sequence.html)。
